一、功能模块一：知网论文收集与检索式智能记录

针对传统知网文献调研中检索条件易丢失、繁琐手工导出的弊端，系统开发了智能化的“知网论文收集与检索式记录”工作台：

⚙️ 双模定向采集模式自由切换
  • 作者全量模式 (Author Mode)：锁定知名法学名家（如王迁、崔国斌、蒋舸、孔祥俊），穿透抓取其历年发表的学术成果，建立作者学术全景档案；
  • CLSCI 核心期刊模式 (Journal Mode)：限定在 16 种法学顶级核心期刊白名单（《法学研究》《中国法学》《中外法学》等），自动过滤非论文短讯，提取高质量长篇理论文献。
💾 检索式持久化沉淀与复现

法学课题往往需要经历多轮检索调试。工作台内置持久化存储：

  • 用户输入复合检索语法（如 主题:(视听作品) AND 核心期刊:(CLSCI)）；
  • 点击 💾 保存当前检索式，自动记录检索逻辑、时间戳与预估文献量；
  • 历史检索式随时一键重新载入，让学术调研的每一步探索都完全可复核、可复现。

三、功能模块三：Agent Prompt 清单与 SOP 执行中枢

将团队资深法学研究者沉淀的文献剖析经验，固化为标准化、可执行的智能体提示词中枢：

Prompt 1：论文精读整理

定位：微观文本提取
驱动大模型按“问题提出、学说争议、制度方案、论证链条、精确页码金句”五维标准提取，严禁脱离原文推论。

Prompt 2：争议结构提炼

定位：中观观点对抗
专门解构对立学说阵营，归纳肯定说、否定说与折中说的理论前提、论据支柱与反驳漏洞，输出对立矩阵。

Prompt 3：学术趋势总结

定位：宏观立法沿革
剖析某一法域在历次修法（如著作权法第三次修改）前后的理论转向，预测未来司法裁判与立法完善趋势。

🔌 无状态 API 交互窗口：零数据泄露的大模型联动通道
工作台专设“API 接入窗口”选项卡。用户可自由配置 DeepSeek、OpenAI 或本地部署的 Ollama API Key。系统自动将当前勾选的文献卡片材料与所选 Prompt 打包组合成标准 Payload，一键调用大模型。全程无任何第三方商业云服务器中转，保障高校与律所核心未公开课题的绝对保密！

四、功能模块四：阅读历史、解除 8 条限制与 Fork 体系

针对早期版本存在的条目限制问题，系统完成了底层存储与状态机的重构：

🚀 彻底解除历史条目数量限制

全面打破原版仅限存储 8 条的物理瓶颈，支持无上限的学术阅读轨迹持久化。系统自动记录研读者浏览、加星标、复制引注的全部学术足迹，形成连续完整的科研历程档案。

🌿 学术 Fork 派生私有研究分支

研读者可以将系统沉淀的公共文献卡片或争议专题一键“Fork”到个人工作空间。在保留原始作者观点的同时，自由增补个人批注、质疑意见与论证草稿，实现公共知识与个人思考的完美解耦。

五、功能模块五：现有争议专题与作者研究路径

初学者进入新法域最苦恼的是“只知散文不知脉络”。工作台通过结构化图谱瞬间化解此难题：

争议焦点专题 主流肯定说观点与代表学者 主流否定说观点与代表学者 折中/制度妥协方案
1. 视听作品范围与权利归属 主张扩大外延，短视频及非摄制画面均可构成，由制作者享有原始著作权 (王迁) 坚持严格摄制要件，反对任意扩大投资人垄断范围，强化创作者权益 (学者A) 区分“实质创作”与“机械投资”，建立著作权与邻接权双轨保护
2. 数据产权与不正当竞争法规制 主张设立数据排他性财产权，激励数字要素投入 (学者B) 反对绝对赋权，主张行为法救济，遵循反不正当竞争法动态衡平 (孔祥俊) “三权分置”框架下的持有权与使用权配置
3. AIGC 生成物可版权性认定 肯定说：用户具有实质独创性构思与提示词微调，属于创作工具 (学者C) 否定说：缺乏人类主体创作意图与表达，仅属公有领域成果 (学者D) 附条件保护：根据人机协同程度判定有限财产权
📈 作者研究路径 (Author Trajectories)：透视学术思想十年嬗变
系统不仅记录争点，还支持切换至“作者研究路径”。以王迁教授为例，系统串联其从 2010 年论网络传播权、到 2020 年著作权法修改对视听作品的解读、再到 2024 年对人工智能生成物的反思，帮助研读者看懂一位学术大家如何伴随立法沿革不断深化其理论体系。
