# 📚 知网学术论文智能采集与整理工具 (CNKI Spider Standalone)

本工具从法学工作台 LexTrace 中**完整独立抽离**，是一个轻量、高保真且功能完备的知网论文采集与文本提取工具。无需启动任何前端页面、Node 服务或本机 HTTP 桥接，双击即可在 macOS 终端中运行。

---

## 🌟 核心特性

1. **双轨采集模式（支持作者论文集全量下载）**：
   - **✍️ 作者模式 / 全量采集模式（新功能）**：专为整理特定专家学者（如王迁、崔国斌、蒋舸、冯术杰等）的个人成果库设计。**完全解除期刊限制**，检索出来的所有论文按列表顺序全部下载并解析。
   - **🎯 法学核心期刊过滤模式**：内置 16 种法学核心期刊（CLSCI）白名单，自动过滤并跳过非目标期刊，专为法学专题调研打造。
2. **免重复登录（Cookie 持久化）**：
   - 挂载独立的 Chrome 用户配置目录（`cnki_chrome_data/`），首次登录校园网/CARSI 或知网账号后自动保持会话，后续运行免去重复登录困扰。
3. **官方 EndNote 高精度引注元数据提取**：
   - 自动化调用知网官方导出接口（`/dm8/API/GetExport`），精准获取规范题名、作者、卷期、起止页码、DOI 与标准引注字符串，杜绝网页抓取可能产生的截断或缺失。
4. **PDF 按真实出版年份自动归档**：
   - 根据论文实际出版年份，自动整理至 `data/{年份}/{题名}__{稳定ID截断}.pdf`，告别杂乱的下载文件夹。
5. **LLM/RAG 就绪的分页文本提取（PyMuPDF）**：
   - 自动将下载的 PDF 解析为逐页文本，每页顶部标注 `[[PDF_PAGE:n]]` 显式标柱并保存至 `txt/` 目录。
   - 同步输出 `page_index/{题名}.json`，记录字符偏移区间与印刷页码映射候选，为 AI 问答溯源和精确引注核验奠定基础。
6. **增量采集与去重机制**：
   - 启动时自动扫描本地已有 PDF 与元数据清单，已下载的文献自动跳过，支持断点续采。
7. **可选 Obsidian 知识库联动**：
   - 默认作为纯净下载器（不写入外部软件）；需要时可在交互菜单或配置中开启，自动在 Obsidian 中生成包含 YAML Frontmatter 的待审核笔记卡片。

## 🚀 快速启动指南

### 方式一：macOS 双击运行（推荐，最简便）

1. 打开访达（Finder），进入 `cnki_crawler` 文件夹。
2. 双击运行 **`启动知网爬虫.command`**。
3. 终端窗口将自动弹出并呈现交互式菜单。

### 方式二：终端命令行运行

在终端中执行：

```bash
cd "~/Downloads/claude 使用专用/cnki_crawler"
```

## 🛠️ 标准操作四步法

无论选用哪种模式，运行流均符合直觉的人机协作体验：

### 第一步：启动与登录
1. 终端启动后，会自动打开一个专属的 Chrome 浏览器窗口，并导航至**知网高级检索页**。
2. 在 Chrome 中完成**知网/校园网登录**（例如 CARSI 认证、复旦 VPN、机构 IP 绑定等）。
3. 登录成功后，切回终端窗口，**按【回车键】**进入下一步。
   *(注：得益于 `cnki_chrome_data`，首次登录后下次通常无需重复登录)*

### 第二步：检索与设置
1. 在 Chrome 页面中输入检索条件：
   - 若使用**【作者模式】**：在作者栏输入学者姓名（如“王迁”），点击检索。
   - 若使用**【期刊模式】**：在主题/篇名中输入关键词（如“商标恶意注册”），点击检索。
2. 检索出结果后，建议点击右上角将每页显示条数调整为 **【50条】**，以减少翻页频次。
3. 切回终端窗口，**按【回车键】**正式开始自动采集！

### 第三步：全自动批量下载与解析
- 爬虫会自动遍历当前结果页上的每篇文献：
  1. 校验期刊（作者模式全量放行；期刊模式按白名单校验）。
  2. 自动在新标签页打开论文详情，抓取摘要、关键词、基金项目。
  3. 异步请求官方 EndNote 导出数据，解析标准引注。
  4. 自动点击 PDF 下载，并将文件重命名归档到 `data/{年份}/` 目录。
  5. 自动用 PyMuPDF 抽取文本，在 `txt/` 目录生成包含 `[[PDF_PAGE:n]]` 的文本。
  6. 自动写入 `metadata/{ID}.json` 索引文件。
- 当前页全部完成后，爬虫将**自动点击“下一页”**继续采集，直至最后一页。

### 第四步：完成与统计
- 采集完成后，控制台将输出本次采集的完整汇总报告（成功篇数、跳过篇数、耗时等）。
- 按回车键退出即可，所有文件已整齐归档。

## 💡 命令行高级参数（适用于自动化脚本）

如需通过脚本调用或免交互运行，`run_spider.py` 支持丰富的命令行参数：

| 参数 | 说明 | 示例 |
| :--- | :--- | :--- |
| `--mode author` 或 `--no-filter` | 启动作者模式（解除期刊过滤，检索到的文献全部下载） | `python3 run_spider.py --mode author` |
| `--mode journal` | 启动期刊过滤模式（按 CLSCI 核心期刊白名单过滤） | `python3 run_spider.py --mode journal` |
| `--author "姓名"` | 指定核验作者姓名（支持逗号分隔多个作者） | `python3 run_spider.py --mode author --author "崔国斌"` |
| `--strict` | 期刊模式下启用严格全字匹配 | `python3 run_spider.py --mode journal --strict` |
| `--obsidian` | 开启在 Obsidian 知识库中同步生成待审核笔记卡片 | `python3 run_spider.py --obsidian` |
| `--no-txt` | 仅下载 PDF 和元数据，不提取分页 TXT 文本 | `python3 run_spider.py --no-txt` |

## ⚙️ 常见配置自定义 (`config.py`)

如需修改默认值，可直接编辑 `config.py`：
- `RUN_MODE`: 默认运行模式（`"journal"` 或 `"author"`）。
- `TARGET_JOURNALS`: 目标期刊白名单列表。
- `DATA_ROOT`: PDF 保存目录（默认为本项目下的 `data/`）。
- `TXT_DIR`: 分页 TXT 保存目录（支持环境变量 `CNKI_TXT_DIR`）。
- `AUTO_CREATE_OBSIDIAN_STUB`: 是否自动联动 Obsidian（默认 `False`）。
- `OBSIDIAN_VAULT_ROOT`: Obsidian 库根目录。

## ❓ 常见问题排查 (FAQ)

### Q1: 知网弹出滑动拼图验证码怎么办？
- 当下载频次过快或知网风控时，浏览器可能会弹出滑动验证码。
- **解决方案**：程序内置了验证码检测机制。终端会打印 `⚠️ 知网详情页/下载要求滑动验证，请手动完成后按回车继续……`。此时只需在 Chrome 浏览器中顺手拖动滑块完成验证，然后回终端按回车即可继续自动采集。

### Q2: 提示 Chrome 无法启动或连接被拒绝？
- 请检查是否有其他以相同 `--user-data-dir` 启动的 Chrome 实例未完全退出。可尝试在终端运行 `killall "Google Chrome"` 或关闭多余的自动化窗口后重试。

### Q3: 如何重新下载已存在的文件？
- 爬虫默认具备增量去重保护，在 `data/` 和 `metadata/` 中存在的文件不会重复下载。如需重新下载，只需将 `data/` 和 `metadata/` 中的对应文件删除或移出即可。
