## 🌟 方案一：Vercel 30秒一键云端托管（强烈推荐，最简单）

Vercel 是目前全球公认部署 Next.js 最平滑、最稳定的云平台。针对 GitHub 私有仓库完全免费，并且构建出的网页拥有全球高速 CDN，随时通过手机、iPad 或他人电脑访问。

### 详细实操步骤（仅需点击鼠标 4 次）：

1. **登录 Vercel**：
   - 打开官网：[https://vercel.com/signup](https://vercel.com/signup)；
   - 点击 **"Continue with GitHub"**，直接用您当前的 GitHub 账号（`endangered-xiezhi`）授权快捷登录。
2. **导入私有仓库**：
   - 进入控制台（Dashboard），点击右上角蓝色的 **"Add New..." ➔ "Project"**；
   - 在左侧 **"Import Git Repository"** 列表中，找到您的私有仓库 **`ob-legalpaperwriting`**；
   - 点击仓库右侧的 **"Import"** 按钮。
3. **确认构建设置并部署**：
   - 项目已在根目录为您预置了标准的 `vercel.json` 配置文件，全部参数会自动识别；
   - 无需更改任何环境变量或复杂设置，直接点击底部的 **"Deploy"** 按钮！
4. **即刻上线**：
   - 等待约 40 秒，页面会放起彩带礼花，提示部署成功！
   - 您将获得一个专属的二级域名（例如 `https://ob-legalpaperwriting.vercel.app`）；
   - **隐私保障**：所有人只能看到渲染后的文献工作台界面，您的 GitHub 私有仓库代码、大纲与历史版本外人绝对无法查看。
   - **自动持续更新**：未来只要您在本地执行 `git push`，Vercel 就会自动在云端感知并全自动重新发布最新版本，无需手动再次操作！

## 💻 方案二：GitHub Codespaces 云端工作台（免装环境，浏览器即用）

如果您在外出差、借用公用电脑、或使用 iPad，不想在电脑上安装 Node.js 与 Python，可以使用 GitHub 官方提供的 **Codespaces** 云端开发机（每个月免费赠送 60 小时）。

### 详细实操步骤：

1. 打开您的 GitHub 仓库页面：[https://github.com/endangered-xiezhi/ob-legalpaperwriting](https://github.com/endangered-xiezhi/ob-legalpaperwriting)；
2. 点击绿色的 **"Code"** 下拉按钮；
3. 切换到 **"Codespaces"** 选项卡；
4. 点击 **"Create codespace on main"**（基于已配置好的 `.devcontainer` 环境）；
5. 此时浏览器会自动打开一个完整的云端 VS Code 界面：
   - 云端服务器已全自动装好 Python 3.11、Node.js 22 和所有爬虫依赖；
   - 端口 3000 和 8765 已自动开启端口转发；
   - 您可以直接在浏览器里查看 538+ 篇文献阅读卡、运行爬虫或双击启动服务！
