执行摘要：传统研究困局与闭环突破

Executive Summary

传统法学研究的三大结构性瓶颈

  • 知网摄入效率割裂：手工检索下载繁琐，引注卷期号、起止页码、DOI 经常残缺遗漏。
  • 笔记与原版 PDF 视窗断层：笔记记在文档里，复核原文论证时需重复检索几十页长文。
  • 通用 AI 辅助的“伪学术幻觉”：缺乏法学专业知识库切片，编造非真实的学说观点与页码。

法脉 LexTrace 的闭环破局方案

  • CNKI 双模全量自动化采集：免重复登录，EndNote 官方元数据高精度提取与结构化导出。
  • PDF++ 原生分屏双向穿透：文献卡双击精准跳转原版高亮，显式页码标柱严防伪证。
  • 学说脉络对比与内生化工作台：忠实提取问题的提出、理论分析与方案，支持本地安全大模型。

零代码基础学者：3 分钟极速装配路线图

Novice Turnkey Guide
01STEP

获取私有仓库代码至本机

通过 Git 克隆或直接在 GitHub 私有仓库页面点击“Code ➔ Download ZIP”下载解压到本机。

git clone https://github.com/endangered-xiezhi/ob-legalpaperwriting.git
02STEP

运行小白专属一键启动脚本（全自动装配）

macOS 用户在访达中鼠标双击项目根目录下的 一键安装与启动_小白专属.command。脚本会自动检测 Python 与 Node.js 环境，缺失时自动调用极速安装程序，并使用国内镜像源安装依赖。启动成功后自动为您在浏览器中打开工作台。

双击运行: 一键安装与启动_小白专属.command (或终端运行 ./install_dependencies.sh)
03STEP

在 Obsidian 中无感打开知识库

下载安装 Obsidian 官方客户端，点击“打开本地文件夹作为仓库 (Open folder as vault)”，选中本项目中的 vault/ 文件夹即可。所有 4 款插件、中文界面、PDF++ 视窗联动均已预置并开启，无需做任何手动配置！

打开路径: ob-legalpaperwriting/vault/ ➔ 点击 00_知识产权研究导航.md
