# 法脉 LexTrace (ob-legalpaperwriting)

> 方便法学研究生一键收集论文并转化为研究工具。所有论文阅读卡均经过学术提炼与转化性使用，无商业原文复制。

## 📖 项目简介

**法脉 LexTrace** 是专为法学学术研究、研究生论文写作及学位答辩设计的**本地化法学研究工作台与知识库系统**。

它解决了传统法学论文检索零散、阅读笔记难以结构化沉淀、AI无法精准核验引注页码的痛点，形成了从**知网自动化摄入 ➔ 结构化阅读卡转化 ➔ 本地知识库联动 ➔ AI 学说争议分析工作台**的完整闭环。

## 🌟 核心功能模块

### 1. 🤖 知网学术双模采集器 (`cnki_crawler/`)
- **✍️ 作者模式 / 全量采集模式**：专为整理王迁、崔国斌、蒋舸、冯术杰等特定学者成果库设计，完全解除期刊限制，检索结果全量下载并自动归档。
- **🎯 法学核心期刊模式**：内置 16 种 CLSCI 法学核心期刊白名单，精准筛选高质量论文。
- **免重复登录**：持久化保存校园网/CARSI认证登录态。
- **官方 EndNote 解析**：异步调用知网官方导出接口，高精度提取卷、期、起止页码、DOI 等引注元数据。
- **逐页标柱文本提取**：通过 `PyMuPDF` 自动解析 PDF 生成带有 `[[PDF_PAGE:n]]` 显式分页标柱的 TXT 及字符偏移索引，专为大模型精准引注与 RAG 溯源设计。

### 2. 🗃️ 内生化学术知识库 (`vault/知识产权/`)
本项目自带经过深度转化的学术知识库，涵盖 800+ 篇结构化 Markdown 文献卡片与专题图谱：
- **论文库 (`vault/知识产权/论文库/`)**：收录 530+ 篇法学核心文献转化性阅读卡，忠实提取问题的提出、理论分析、制度方案与可核验观点。
- **七大前沿专题 (`vault/知识产权/研究工作台/七大专题/`)**：
  1. AIGC 可版权性与独创性认定
  2. 大模型训练数据的版权风险与合理使用
  3. 网络平台过滤义务与避风港规则
  4. 商业数据保护与确权路径
  5. 反不正当竞争法一般条款与行为类型化
  6. 商标恶意注册的法律规制
  7. 商业秘密保护的数字化转型
- **学术热点与前沿趋势 (`vault/知识产权/研究趋势/`)**：160+ 篇热点预测、争鸣总览与学者学术脉络梳理。
- **学者学派路径**：北大知产、清华研究路径等系统化文献导航。

### 3. 🖥️ 本地交互式法学研究工作台 (`app/` & `local_bridge/`)
- **零外部依赖**：基于 Next.js 与 Python 本机桥接服务，默认直接读取项目内置的 `vault/` 目录，开箱即用。
- **Dataview 兼容导航**：支持双向链接、争议全景图查看、引注样板一键生成。
- **安全与隐私**：所有数据均存储于本地，不上传云端，不外泄研究隐私。

### 4. ⚖️ 知识产权法律法规与典型案例库 (`vault/知识产权/法律法规与典型案例/`)
集成 50 部知识产权核心法律法规、司法解释以及 395 篇最高人民法院权威入库案例与典型案例：
- **法条 ↔ 解释 ↔ 案例立体双链**：以法律条文为中心（商标法87条、专利法82条、著作权法67条、植物新品种保护条例49条等），每个法条均挂载对应司法解释与权威裁判文书，支持 Obsidian 原生双向链接点击穿透。
- **审判参考与跨域规则**：收录管辖、证据、行为保全、惩罚性赔偿等通用诉讼规则，以及最高人民法院法答网精选知识产权审判答问。
- **双端无缝融合**：Web 端工作台与 Obsidian 均可一键定位中心法与分域案例，支持论文写作与案例实证对照。

## 🚀 快速启动

### 方式一：macOS 双击启动（最简便）

1. 双击运行根目录下的 **`启动LexTrace.command`**；
2. 脚本将自动检测依赖、启动本机桥接并启动 Web 服务；
3. 浏览器将自动打开 `http://localhost:3000/` 进入法脉工作台。

### 方式二：命令行启动

```bash
# 1. 安装 Node 依赖
npm install

# 2. 启动 Python 桥接服务 (监听 8765 端口)
python3 local_bridge/server.py

# 3. 在另一终端启动 Web 前端
npm run dev
```

### 方式三：单独使用知网采集器

如需单独采集论文，无需启动网页端：
```bash
cd cnki_crawler
python3 run_spider.py
```
或直接双击 `cnki_crawler/启动知网爬虫.command`，按终端菜单提示选择【作者模式】或【期刊模式】即可。
