## 🏛️ MECE 四层系统架构矩阵 (System Architecture Matrix)

系统严格按照咨询业界互不重叠、完全穷尽（MECE）原则划分为四大支撑层级：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    第四层：用户交互与学术工作台呈现层 (Layer 4)                     │
│   Web 仪表盘 (Next.js 15) │ 15篇/页文献分页 │ 争议焦点/作者路径 │ 检索式/阅读历史与Fork  │
├─────────────────────────────────────────────────────────────────────────────┤
│                    第三层：智能体推理与 Prompt 枢纽层 (Layer 3)                     │
│   法学整理SOP任务单 │ 3大核心 Prompt (精读/争议/趋势) │ 无状态大模型 API 交互窗口  │
├─────────────────────────────────────────────────────────────────────────────┤
│                    第二层：知识图谱与双链双向穿透层 (Layer 2)                     │
│   Obsidian 双链网络 │ PDF++ 逐页标柱穿透 │ YAML 元数据体系 │ 原生 PDF++ 灵感锚点     │
├─────────────────────────────────────────────────────────────────────────────┤
│                    第一层：数据全自动采集与摄入预处理层 (Layer 1)                   │
│   CNKI 双模爬虫 (作者/期刊) │ PyMuPDF 显式分页标柱 │ EndNote/RIS 解析 │ 待审核队列   │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 矩阵明细拆解

| 层次维度 | 核心组件 | 技术底座 | 业务价值与学术赋能 |
| :--- | :--- | :--- | :--- |
| **Layer 1: 摄入层** | `cnki_crawler/` | Selenium + PyMuPDF | 自动完成作者全量与 CLSCI 筛选论文抓取，自动生成带有 `[[PDF_PAGE:n]]` 显式分页标柱的结构化文本。 |
| **Layer 2: 沉淀层** | `vault/知识产权/` | Obsidian Native Plugins | 预装 **PDF++**、**Dataview**、**Enhancing Mindmap**，实现阅读卡与原版 PDF 视窗毫秒级联动。 |
| **Layer 3: 智能体层** | `app/obsidian-workbench.tsx` | Next.js 15 + Prompt SOP | 内置三大核心法学 Prompt，支持无状态 API 窗口对接 DeepSeek/OpenAI，一键组装物料并驱动推演。 |
| **Layer 4: 展现层** | `local_bridge/` + Web | Python 3 (8765) + Vinext | 15篇/页沉浸式研读、阅读历史与 Fork 机制、检索式持久化记录，采用斯坦福法学评论温润宣纸色排版。 |

## 🌟 核心功能特性展示 (Feature Showcase)

### 1. 15 篇/页黄金学术分页与微型操作栏
- 采用国际法学期刊标准的 15 篇分页控制，告别无限滚动的视觉疲劳；
- 整合紧凑的 `.row-action-group` 微型胶囊：
  - `★ 重点`：一键纳入重点追踪列表；
  - `引注`：一键复制符合《法学引注手册》国标引注代码；
  - `+ 材料`：勾选进入智能体分析物料包；
  - `OB ↗`：毫秒级直达 Obsidian 原文笔记与关联 PDF。

### 2. 知网论文收集与检索式记录
- **双模采集**：作者模式（权威学者文献全量）与期刊模式（CLSCI 16 种核心期刊）；
- **检索式持久化**：一键保存复杂的复合检索逻辑，随时回溯历史调研路径，保证学术探索的可复现性。

### 3. Agent Prompt 清单与 SOP 执行中枢
- 精致的无前缀胶囊选项卡：`SOP 任务单`、`1. 论文整理 Prompt`、`2. 争议结构 Prompt`、`3. 总结趋势 Prompt`、`API 接入窗口`；
- 无状态 API 窗口直接对接大模型（如 DeepSeek、Claude、OpenAI），本地数据安全不泄露。

### 4. 现有争议专题与作者研究路径
- **7 大争议焦点矩阵**：全景对比肯定说、否定说与折中说的理论假设与论据链条；
- **作者研究路径**：梳理知名学者在历次修法背景下的学术观点深化轨迹。

### 5. 阅读历史、解除条目限制与 Fork 体系
- 彻底取消旧版 8 条记录的物理瓶颈，支持无上限的学术足迹管理；
- 独创法学学术 Fork 机制，支持学者派生私有研究分支，保留个人深度思考。
