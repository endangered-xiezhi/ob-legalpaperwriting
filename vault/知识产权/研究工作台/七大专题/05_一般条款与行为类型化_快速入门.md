# 一般条款与行为类型化：从一个 AI 特效纠纷入门

> [!abstract] 先记住一句话
> 这个专题不是在问“原告辛苦做出来的东西要不要保护”，而是在问：**专门知识产权法没有禁止被告时，法院凭什么、又能在多大范围内用《反不正当竞争法》一般条款说它不正当？**

这页不是论文清单，而是一条可顺着讲出来的理解路径。阅读时始终带着下面这个案例走；每增加一个事实，就看结论是否改变。

## 一、贯穿全页的案子：别人做出了相似 AI 特效，算不算“偷成果”

甲公司经营短视频平台，花费大量资金开发“照片变漫画”特效。乙公司经营修图 App，通过甲平台面向普通用户开放的功能反复取得输入、输出样本，调校出效果相近的新模型，并在自己的 App 中上线。

为了便于理解，我们分五次追加事实：

1. **最初事实：**乙没有复制甲的软件代码，也拿不到甲的模型参数；它只是取得了大量公开可见的输入、输出结果。
2. **事实 A：**乙绕过了甲设置的调用频率限制，但没有盗取密码，也没有进入内部服务器。
3. **事实 B：**乙的新功能效果相似，却增加了批量修图和离线处理，双方用户群也不完全相同。
4. **事实 C：**甲的平台靠广告和用户停留变现；乙的工具使用户无需进入甲平台，甲的流量下降。
5. **事实 D：**乙在宣传中写“比甲平台更快”，但没有冒充甲，也没有让用户误以为双方存在合作。

这个合成案例借用了库内“变身漫画特效”、知识蒸馏、平台交互和广告屏蔽等研究中的共同难题，**不是对某一真实案件事实的复述**。它的作用是让你看见：同一句“乙搭了甲的便车”，在不同法律路径下可能得到完全不同的答案。

## 二、先不要急着站队：把直觉换成六个递进问题

你可以把本专题记成一棵纯文字判断树：

```text
入口：甲只是利益受损，还是竞争机制受损？
│
├─ 第一步：著作权、专利、商业秘密、合同或反法具体条款能不能处理？
│   ├─ 能：先用具体规则，不能为了避开构成要件而跳到一般条款。
│   └─ 不能：继续问；“专门法不保护”不等于“自动不正当”。
│
├─ 第二步：专门法的沉默是什么意思？
│   ├─ 有意留给公众自由使用：一般条款原则上不得翻案。
│   └─ 只是没有覆盖新的行为机制：一般条款仍可能有限介入。
│
├─ 第三步：被告到底多做了什么？
│   ├─ 只有学习、模仿、获益：通常不够。
│   └─ 还有混淆、欺骗、破坏接触控制、技术妨碍、实质替代等：进入下一步。
│
├─ 第四步：所谓“商业道德”能不能翻译成可验证的损害？
│   ├─ 只剩“投入很大”“不劳而获”：警惕道德直觉代替法律判断。
│   └─ 能说明消费者受骗、交易成本上升或竞争机制被扭曲：违法性增强。
│
├─ 第五步：应归入什么行为类型？
│   ├─ 破坏商品或服务本身：保护强度较高。
│   └─ 只改变一种流量或盈利方式：原则上容忍竞争，另有公共利益损害时例外。
│
└─ 第六步：救济会不会反过来创设一项“准知识产权”？
    ├─ 会让甲长期控制公开信息、模型效果或商业模式：应限缩。
    └─ 只禁止额外不正当手段：较容易与竞争自由兼容。
```

整套争议可以再压缩成一句因果链：

```text
专门法边界
→ 找到复制之外的行为增量
→ 把道德评价翻译成竞争损害
→ 归入可重复的行为类型
→ 检查竞争关系、因果关系与阻却事由
→ 用不过度封锁竞争的方式救济
```

## 三、第一关：知识产权法不保护，一般条款能不能“接住”

### 路径 1：蒋舸——先相信成熟规则，不要一遇到新问题就自由衡量

- **担心什么：**法官觉得乙“占了便宜”，便绕开著作权法、专利法或商业秘密法已经设置的门槛，直接用“诚实信用”判甲胜诉。这样一来，具体规则的保护期限、客体范围和例外都会失去意义。
- **大白话：**具体知识产权规则像已经反复使用过的答题模板；一般条款像没有模板的开放作文。开放作文不是不能写，但成本高、波动大，所以应当后置。
- **放进案例：**如果甲不能证明模型参数受著作权、专利或商业秘密保护，不能只说“研发花了很多钱”，就让一般条款给模型效果补上一项排他权。先问乙是否另有绕过措施、混淆用户或实质破坏服务的行为。
- **最强反问：**技术发展太快，等具体规则成熟，创新者的成果早被复制完了，难道法律只能袖手旁观？
- **回应：**可以保留一般条款，但它只能处理可以说清楚的额外不正当行为，不能把“没有专有权”直接改写成“享有类专有权”。
- **口头怎么说：**“蒋舸不是绝对排斥一般条款，而是从认知经济性出发要求具体规则优先。一般条款可以补充，但必须证明它比既有图式多解决了一个真正的竞争损害问题。”
- **原文入口：**[[知识产权/论文库/知识产权法与反不正当竞争法一般条款的关系——以图式的认知经济性为分析视角_蒋舸|蒋舸：知识产权法与一般条款的关系]]

### 路径 2：解亘——可以进入分析，不等于一定给救济

- **担心什么：**一般侵权法或一般条款被用来替代立法，法院通过个案实际上创设新权利，却没有能力评估这种权利对整个市场的长期成本。
- **大白话：**法院可以听甲讲这个案子，但“可以进门”不等于“进门就赢”。越靠近著作权、专利等专有权的边界，越要推定公众有行动自由。
- **放进案例：**乙学习公开输出结果的行为位于知识产权法“周边”。如果没有盗取参数、破坏真正接触控制或落入成熟不正当竞争类型，应先推定乙的行为不具备足够违法性，而不是因为甲受损就判赔。
- **最强反问：**如果遮断推定过强，新出现的恶劣手段尚未被列入具体条款，受害者怎么办？
- **回应：**解亘保留的是“可能性上的兜底”：特殊案情、黑名单类型、典型案例积累仍可推翻推定；他反对的是“结果上的兜底”。
- **口头怎么说：**“知识产权法对周边利益具有遮断效果，但遮断的不是法院思考，而是从损害直接跳到责任。一般条款可以评价，成立责任仍需额外类型和更强违法性。”
- **原文入口：**[[知识产权/论文库/侵权法在私法秩序生成中的谦抑性——以竞争秩序的生成为核心_解亘|解亘：侵权法在竞争秩序生成中的谦抑性]]

### 路径 3：孔祥俊——可以补充，但底线是不得抵触专门法政策

- **担心什么：**“知识产权法是冰山，反不正当竞争法是海水”的比喻被误读为：凡是专门法不保护的，反法都要兜底。结果可能是过期专利、无独创性元素和本应自由使用的信息重新被垄断。
- **大白话：**补充保护不是“捡漏保护”。专门法故意不保护或停止保护的东西，一般条款不能把它捡回来续命。
- **放进案例：**如果模型功能和效果本来就不属于著作权表达，一般条款不能直接禁止所有相似功能；但乙若通过欺骗、盗密或破坏系统取得优势，反法仍可针对这些手段有限介入。
- **最强反问：**如何区分“立法者故意不保护”与“立法者还没来得及规定”？
- **回应：**不能只看条文有没有写；要检查专门法为何设置客体、期限、独创性或秘密性门槛，以及拟给予的救济是否实际上绕开这些门槛。
- **口头怎么说：**“孔祥俊把兜底保护改造成有限补充保护，核心底线是不得抵触专门法立法政策。关键不在有没有保护空白，而在填空以后会不会架空公有领域和竞争自由。”
- **原文入口：**[[知识产权/论文库/反不正当竞争法补充保护知识产权的有限性_孔祥俊|孔祥俊：补充保护知识产权的有限性]]

### 路径 4：孙山——不要谈谁补谁，先把两部法保护的法益分开

- **担心什么：**“兜底”或“补充”的说法仍然默认反法可以顺着著作权法留下的空白继续保护，从而造成重叠和过度保护。
- **大白话：**著作权法和反法不是前后接力，而是两条平行车道。前者保护独创性表达形成的绝对权；后者只在特定竞争条件下保护未上升为绝对权的利益。
- **放进案例：**甲不能把模型效果当成作品表达交给反法继续保护；如果乙使用非独创性要素造成混淆，反法保护的是防止混淆的竞争法益，而不是给甲模型本身一项权利。
- **最强反问：**非独创性要素如果确有巨大商业价值，为何只能在混淆等有限场景保护？
- **回应：**价值高不等于应赋予排他权。有限保护正是为了区分“有商业利益”与“任何使用都要许可”。
- **口头怎么说：**“平行保护说把问题从法律之间谁兜底，改写成各自保护什么法益。反法处理的是具体竞争行为，不是替著作权法扩大客体。”
- **原文入口：**[[知识产权/论文库/著作权法与反不正当竞争法的“平行保护”界分_孙山|孙山：著作权法与反法的平行保护]]

### 这一关的入门结论

四条路径的措辞不同，但共同反对以下跳跃：

```text
甲有投入
→ 形成有价值成果
→ 乙利用并让甲受损
→ 所以乙违法
```

更稳妥的表达应是：

```text
甲有投入和利益
→ 只证明案件值得审查
→ 继续查专门法政策、乙的行为手段和竞争损害
→ 只有额外要件成立，反法才有限介入
```

## 四、第二关：“搭便车”到底是一条理由，还是一个情绪标签

### 路径 5：冯术杰——搭便车可以被规制，但不是“不劳而获即违法”

- **担心什么：**一方面，如果完全不承认寄生性利用，严重攫取他人商誉的行为可能漏网；另一方面，若把节省成本一律定为违法，模仿、学习和跟进创新都会被禁止。
- **大白话：**搭便车是一种现象，不是自动生效的罪名。你仍要说明搭的是什么车、为什么这种利用超过竞争应当容忍的范围。
- **放进案例：**乙借甲模型的输出降低训练成本，形式上确实借用了甲的投入。但若没有冒充甲、没有夺取甲的商誉，也没有扭曲优胜劣汰机制，仅仅“训练得更省钱”还不足以定性。
- **最强反问：**如果允许竞争者省掉几千万研发成本，谁还愿意做第一家创新者？
- **回应：**创新激励是重要因素，却不能替代构成要件；需要继续证明持续、系统性替代会怎样破坏创新投入机制，并检查反向工程、转换性创新和消费者福利。
- **口头怎么说：**“搭便车不是结论而是问题入口。反法要规制的不是所有借力，而是不当利用商誉或通过特定手段扭曲竞争的借力。”
- **原文入口：**[[知识产权/论文库/“搭便车”的竞争法规制_冯术杰|冯术杰：“搭便车”的竞争法规制]]

### 一个很有用的反例：关键词隐性使用

孔祥俊用“关键词隐性使用”说明一般条款为什么不能逃避具体条款：乙在搜索后台购买甲的标识作为关键词，却没有在页面冒充甲，也没有造成混淆。若商标法和反法混淆条款都因缺少混淆而不成立，就不应再以“截流”“搭便车”为由转向一般条款。

- **担心什么：**具体条款要求混淆，法官却因为不喜欢乙的行为，改用一般条款绕过混淆要件。
- **大白话：**考试没达到及格线，不能换一张没有分数线的卷子让它及格。
- **最强反问：**乙明明靠甲的知名度把潜在顾客带走，为什么不是伤害？
- **回应：**竞争本来就在争夺顾客。法律若选择“混淆”为商业标识保护边界，就不能把没有混淆的顾客转移本身再包装成违法。
- **口头怎么说：**“对具体条款已经评价过的行为，一般条款不能成为降低证明标准的逃生通道。”
- **原文入口：**[[知识产权/论文库/关键词隐性搜索的不正当竞争定性_孔祥俊|孔祥俊：关键词隐性搜索的不正当竞争定性]]

## 五、第三关：“违反商业道德”不能只靠法官说感觉不好

### 路径 6：孔祥俊——从经验道德转向竞争功能

- **担心什么：**“诚信”“不劳而获”“违反公认道德”过于抽象，容易把法官的个人好恶变成违法标准。
- **大白话：**不要问“同行看着顺不顺眼”，要问“这个行为究竟让市场哪里坏掉了”。
- **放进案例：**乙让甲流量下降，并不当然违反商业道德；需要说明乙是否欺骗用户、排斥竞争、破坏正常选择，或使竞争不再由产品质量和效率决定。
- **最强反问：**竞争功能、市场扭曲也很抽象，法官仍可随意解释。
- **回应：**功能标准至少强迫裁判者说明受影响的机制、对象、因果关系和证据，比单写“有违诚信”更可检验；随后还要用类型化进一步收紧。
- **口头怎么说：**“商业道德不是世俗道德在市场里的翻版，而是识别竞争是否被扭曲的功能标准。经营者受损只是现象，竞争机制受损才是规范理由。”
- **原文入口：**[[知识产权/论文库/反不正当竞争法商业道德标准的流变与重构_孔祥俊|孔祥俊：商业道德标准的流变与重构]]

### 路径 7：蒋舸——行业惯例只是信息，不是答案

- **担心什么：**大平台或既有经营者可能把有利于自己的做法塑造成“行业惯例”，再借法院之手阻止后来者创新。
- **大白话：**大家一直这么做，只能说明“它存在”，不能说明“它合理”。
- **放进案例：**甲平台说“业内都禁止自动调用”。法院仍要追问：这项惯例是在保护系统安全，还是仅仅封锁公开信息和维持广告收入？它降低还是增加了用户和市场的成本？
- **最强反问：**如果不用行业惯例，法官并不懂技术市场，凭什么判断商业道德？
- **回应：**惯例可以作为降低信息成本的证据，但要接受功能检验；专家意见、技术影响、消费者选择和替代效果共同说明其正当性。
- **口头怎么说：**“商业惯例是证据代理，不是规范来源。存在的惯例只有在能解释其竞争功能时，才可能转化为商业道德判断。”
- **原文入口：**[[知识产权/论文库/竞争行为正当性评价中的商业惯例因素_蒋舸|蒋舸：竞争行为评价中的商业惯例]]

### 路径 8：冯术杰——不要保护一个商业模式免受正常竞争，优先检查消费者

- **担心什么：**“非公益必要不干扰”把自由竞争的顺序倒过来：只要乙干扰甲，就先推定违法，再让乙证明自己代表公共利益。
- **大白话：**竞争本来就是抢用户、改商业模式。不能先要求后来者证明“我对全社会有用”，才允许它碰旧平台的奶酪。
- **放进案例：**乙减少了甲的流量，但同时让用户更快获得修图服务。除非用户受骗、功能受破坏或竞争被封锁，单纯冲击旧流量模式更接近正常竞争。
- **最强反问：**把消费者利益放在中心，会不会忽略经营者的研发激励和市场秩序？
- **回应：**消费者标准不是唯一数据点，但它能防止把竞争者利益等同于竞争本身；经营者利益仍可通过混淆、诋毁、盗密和具体损害机制进入分析。
- **口头怎么说：**“反不正当竞争法保护的是竞争，而不是既有商业模式。判断新型行为，应特别说明消费者是否被误导、选择是否被压缩，而不能仅以干扰竞争者为由推定违法。”
- **原文入口：**[[知识产权/论文库/知识产权条约视角下新型竞争行为的规制_冯术杰|冯术杰：知识产权条约视角下新型竞争行为的规制]]

### 这一关怎么形成自己的判断

把“乙不讲武德”改写成四个可核验句子：

1. 乙用了什么具体手段？
2. 谁的选择、交易机会或系统功能被怎样影响？
3. 这种影响是竞争本身造成的，还是行为方式额外造成的？
4. 禁止乙以后，消费者、后来者和创新会付出什么成本？

如果四问答不出来，“商业道德”很可能仍只是结论标签。

## 六、第四关：双方不是同行，还能不能叫“不正当竞争”

### 路径 9：吴伟光——竞争的本质是争夺交易能力，不是卖同一种商品

- **担心什么：**如果只承认同类商品之间的直接竞争，平台、免费服务、跨界应用和注意力竞争会因为“不同行”而逃出反法。
- **大白话：**卖什么不一样，不代表没有抢同一批用户的钱、时间和注意力。
- **放进案例：**甲是短视频平台，乙是修图 App，产品并非完全替代；但乙的功能可能减少用户进入甲平台的需要，双方仍可能在用户时间、广告收入、模型服务或图片处理需求上形成竞争联系。
- **最强反问：**如果所有经营者都在争消费者钱包，竞争关系岂不是无限扩张，任何公司都能起诉任何公司？
- **回应：**广义竞争关系只解决能否进入反法；具体责任仍要证明行为、损害、因果关系和对应法益。吴伟光还把关系分为对向、直接和间接三类，分别聚焦消费者、具体经营者和公平竞争秩序。
- **口头怎么说：**“现代竞争关系应从商品可替代性转向交易能力，但这只是扩大观察范围，不是降低违法门槛。关系可以宽认，损害和因果仍要严证。”
- **原文入口：**[[知识产权/论文库/对《反不正当竞争法》中竞争关系的批判与重构——以立法目的、商业道德与竞争关系之间的体系性理解为视角_吴伟光|吴伟光：竞争关系的批判与重构]]

你可以用下面三种关系快速定位：

```text
对向竞争：经营者如何争取消费者作出交易
→ 重点看误导、选择与消费者利益。

直接竞争：具体经营者争夺相同或相近交易机会
→ 重点看财产、商誉、秘密与竞争优势。

间接竞争：跨市场行为改变整体竞争秩序
→ 重点看平台开放、技术妨碍、流量结构与市场机制。
```

## 七、第五关：为什么一定要“类型化”，而不能每次都综合衡量

### 路径 10：蒋舸——类型不是多列几个技术名词，而是建立可重复的判断模型

- **担心什么：**网络条款把流量劫持、恶意不兼容、技术干扰等旧案名称写入法条，看似具体，实际上概念交叉、边界模糊，反而增加判断成本。
- **大白话：**把一堆案件标题抄成菜单，不等于总结出了菜谱。
- **放进案例：**不能因为乙“用了 AI”“自动调用”“截走流量”就直接贴标签。需要提炼稳定变量：是否获授权、是否绕过接触控制、是否影响服务正常运行、是否替代核心市场、是否增加新功能、消费者是否受骗。
- **最强反问：**技术变化太快，稳定变量今天有用，明天也可能过时。
- **回应：**所以类型化应围绕行为机制和损害结构，而不是产品名称；仍保留一般条款处理少数无法归类的行为，并通过案例逐步校正。
- **口头怎么说：**“高质量类型化的价值是降低决策成本。它应提炼稳定变量，而不是把流量劫持、AI 调用等技术外观机械写进清单。”
- **原文入口：**[[知识产权/论文库/《反不正当竞争法》网络条款的反思与解释——以类型化原理为中心_蒋舸|蒋舸：网络条款与类型化原理]]

### 路径 11：侯利阳——先问被影响的是“商品本身”还是“一种销售方式”

- **担心什么：**“只要干扰竞争者且无公益必要就违法”会把正常争夺流量、改变盈利方式也纳入禁止。
- **大白话：**把别人的店砸到不能营业，和让顾客不看它的广告，是两种不同的干扰。
- **放进案例：**如果乙的调用导致甲的特效服务无法正常运行，更像破坏商品或服务本身；如果乙只是让用户少看甲的广告、少停留在甲的页面，而甲的功能仍可正常使用，更像改变一种销售方式，原则上应更容忍竞争。
- **最强反问：**在数字平台中，广告、流量和服务往往绑在一起，怎么真正二分？
- **回应：**二分不是看合同怎么写，而是看相关安排是否已经成为用户换取服务的交易条件，以及乙的行为是否使原服务价值无法正常实现。二者重合时，应说明为何销售方式已经转化为服务组成部分。
- **口头怎么说：**“侯利阳用商品与销售方式二分来分配保护强度：破坏商品价值实现，原则保护；只冲击特定盈利路径，原则容忍，除非能证明独立公共利益损害。”
- **原文入口：**[[知识产权/论文库/商品与销售方式二分视角下不正当竞争行为的类型化_侯利阳|侯利阳：商品与销售方式二分的类型化]]

### 两种类型化不是互相替代

```text
蒋舸问：这个“类型”有没有真正降低判断成本？
侯利阳问：不同类型为什么应承担不同的证明责任和干预强度？

前者是类型质量检查；后者给出一种具体分类方法。
```

## 八、把类型放回具体行为：三个一看就懂的边界例子

### 例子 1：广告屏蔽——消费者体验更好，还是破坏“注意力换内容”的交易

杨明强调先做效应分析：屏蔽广告可能改善用户体验，也可能破坏内容平台的收入和内容供给；应比较福利效果和替代方案，不能只因平台收入下降认定违法。

王迁则提供更强的财产利益类比：免费视频前的广告可能是用户以注意力换取内容的接触门槛；专门提供绕过工具，类似提供破坏接触控制的钥匙，因此有规制正当性。

- **担心什么：**一边担心平台把广告模式固化成不可挑战的权利；另一边担心所有人都绕开广告后，免费内容无法持续供给。
- **大白话：**用户讨厌广告是真的，内容不能凭空生产也是真的。问题是屏蔽工具只帮用户管理界面，还是系统性拆掉了交易条件。
- **放进贯穿案：**如果乙只让用户少停留在甲平台，偏向销售方式竞争；如果乙批量替代甲的核心服务，并使甲无法维持免费服务，则干预理由增强。
- **最强反问：**平台自己选择了广告商业模式，为什么法律要保证它永远成功？
- **口头怎么说：**“广告商业模式不当然受保护，但若广告已成为取得内容的交易条件，专门绕过工具可能不只是改善体验，而是在拆除对价机制。仍应结合替代程度和消费者福利判断。”
- **原文入口：**[[知识产权/论文库/互联网广告屏蔽行为的效应分析及规制路径选择_杨明|杨明：广告屏蔽的效应分析]]；[[知识产权/论文库/论规制视频广告屏蔽行为的正当性——与“接触控制措施”的版权法保护相类比_王迁|王迁：视频广告屏蔽与接触控制类比]]

### 例子 2：反爬措施——平台写了“禁止抓取”，不等于法律自动禁止抓取

崔国斌把问题拆成三层：反爬措施本身是否值得保护、底层数据是否受保护、具体获取和使用是否侵害权益。机器人协议只是声明，不当然等于有效技术措施；普通封禁在一定范围内可以合理规避；盗取密码、破解加密等真正破坏接触控制则明显不同。

- **担心什么：**平台把一个技术按钮直接变成法律上的排他权，公共可见信息因此被事实垄断；同时也要防止行为人破坏安全边界。
- **大白话：**门口贴“谢绝入内”和把门锁上不是一回事；翻看公开货架与偷钥匙进仓库也不是一回事。
- **放进贯穿案：**乙变换调用节奏绕过频率限制，并不自动等于盗取模型；若它盗用账户、破解权限或进入内部接口，违法性显著上升。底层输出是否受保护仍要另行判断。
- **最强反问：**如果允许合理规避，平台设置频率限制还有什么意义？
- **口头怎么说：**“技术措施与底层权益必须分层。是否违反平台规则、是否破坏有效接触控制、是否侵害数据或模型利益，是三个不能互相替代的问题。”
- **原文入口：**[[知识产权/论文库/网络反爬虫措施的法律定性_崔国斌|崔国斌：网络反爬虫措施的法律定性]]

### 例子 3：恶意不兼容——真正要看的是有无正当理由和实质排除效果

孔祥俊对“恶意不兼容”的研究说明，技术选择造成不兼容不当然违法。要区分正常产品设计、合理安全管理与针对特定竞争者的排斥；技术名称可以变化，但“选择性排除—缺乏正当理由—造成实质竞争妨碍”这一机制相对稳定。

- **担心什么：**法院把所有不开放接口都判为不正当，也担心头部平台用技术兼容性封锁竞争者。
- **大白话：**不同插头不一定是为了赶走对手；专门识别对手设备并让它不能用，性质就不同。
- **放进贯穿案：**甲限制高频调用可能是安全和容量管理，也可能专门针对乙封锁竞争。需要比较规则是否普遍适用、限制是否必要、有没有较温和接口以及实际排除效果。
- **最强反问：**平台自己的系统，为什么不能自主决定兼容谁？
- **口头怎么说：**“系统控制权不是无限的，但不兼容也不推定恶意。应围绕选择性、正当理由、必要性和竞争排除效果建立类型要件。”
- **原文入口：**[[知识产权/论文库/网络恶意不兼容的法律构造与规制逻辑——基于《反不正当竞争法》互联网专条的展开_孔祥俊|孔祥俊：网络恶意不兼容的法律构造]]

## 九、回到 AI：模型、智能体和知识蒸馏为什么是同一套老问题的新考场

### 路径 12：贾海东——不要保护“模型利益”，要检查“竞争机制是否受损”

- **担心什么：**法院从“模型投入巨大、具有商业价值”直接推到“模型结构参数是竞争利益”，再从相似结果推到乙违法，最终形成没有期限和边界的准知识产权。
- **大白话：**甲有宝贵模型，不等于法律要替甲把所有相似路线封死。真正要看乙靠什么手段竞争、在哪个市场竞争、有没有创造新价值。
- **放进案例：**甲主营短视频，乙主营图片编辑；技术、营收、产品和用户是否指向同一主营市场，需要严格判断。乙若通过公开结果形成离线批处理等新功能，也要检查转换性使用和附属市场规则，不能只看效果相似。
- **最强反问：**若模型结构参数不受版权保护，又允许输出模仿，原创模型开发者如何收回成本？
- **回应：**商业秘密、合同、有效技术措施和针对不正当获取行为的反法仍可保护；但保护对象是手段和竞争机制，而不是把所有价值外溢收回给先行者。
- **口头怎么说：**“模型可以形成竞争利益，但一般条款应从权益—侵害转向竞争—损害。技术边界、主营市场和因果阻断是三道阀门，防止模型利益被财产权化。”
- **原文入口：**[[知识产权/论文库/人工智能模型的竞争利益范畴_贾海东|贾海东：人工智能模型的竞争利益范畴]]

周辉和相关案例研究更强调司法保护的现实需求：模型结构与参数可能凝结开发者投入，直接复制或高度替代会打击创新。但这条路径最需要回应贾海东的追问：投入证明了利益存在，是否也证明了行为不正当？

- **补充入口：**[[知识产权/论文库/人工智能模型的司法保护——以“变身漫画特效”不正当竞争纠纷案为视角_周辉|周辉：人工智能模型的司法保护]]；[[知识产权/论文库/人工智能模型结构和参数的司法保护路径选择以变身漫画特效不正当竞争纠纷案为中心|人工智能模型结构和参数的司法保护路径选择]]

### 路径 13：詹韫如——知识蒸馏要分成“盗取秘密”和“竞争性学习”两条路

- **担心什么：**把所有知识蒸馏都叫“偷模型”会阻碍技术学习；把所有蒸馏都叫反向工程，又可能纵容绕过保密措施取得核心知识。
- **大白话：**偷进厨房拿秘方，和买成品回来反复试吃，不是一件事。
- **放进案例：**乙若绕过合理保密措施取得模型知识，可能进入商业秘密路径；若仅使用有合法处分权的模型或公开输出进行低替代成本反向工程，则可能阻却违法。形式上的搭便车仍须证明其扭曲优胜劣汰机制。
- **最强反问：**反复调用公开接口进行蒸馏，单次都合法，累积到足以替代教师模型时还合法吗？
- **回应：**这正是未决边界。需要结合授权范围、调用规模、替代程度、保密措施、服务成本和竞争机制，而不能只靠“公开”或“搭便车”一个词决定。
- **口头怎么说：**“知识蒸馏应双轨评价：不正当取得受保密模型知识，重点看商业秘密；合法接触后的学习，重点看反向工程、行为方式和竞争机制，搭便车本身不足以证成违法。”
- **原文入口：**[[知识产权/论文库/反不正当竞争法下知识蒸馏违法性的认定_詹韫如|詹韫如：知识蒸馏违法性的认定]]；[[知识产权/论文库/论知识蒸馏作为反向工程的合法性|知识蒸馏作为反向工程的合法性]]

### 路径 14：冯晓青、张云蔚——智能体冲击平台流量，首先可能是创造性竞争

- **担心什么：**平台把用户、界面和流量都当作自己的利益，阻止智能体代用户跨平台搜索、比价和下单；反过来，智能体也可能借用户授权之名超范围取数、滥用无障碍权限。
- **大白话：**帮用户少点几次按钮不是天然违法；拿着用户的一把钥匙打开整栋楼也不是当然合法。
- **放进案例：**若乙通过标准 API、明确授权和最小必要范围调用，且提高用户效率，甲的流量下降更像创造性竞争；若乙绕过接管节点、高频替代核心服务或读取超范围数据，则可能产生实质竞争损害。
- **最强反问：**用户已经授权智能体操作自己的账户，为什么还需要平台同意？
- **回应：**用户只能处分自己的权限和数据，不能当然授权智能体取得第三方数据、绕过平台安全规则或把个人使用规模化为替代服务。
- **口头怎么说：**“智能体规制应采取动态竞争观和行为中心主义：流量下降不是损害结论，授权链、权限范围、技术路径、核心服务替代和用户控制共同决定正当性。”
- **原文入口：**[[知识产权/论文库/智能体交互的反不正当竞争法规制研究_冯晓青_张云蔚|冯晓青、张云蔚：智能体交互的反不正当竞争法规制]]

### AI 延伸的共同逻辑

```text
模型有价值
≠ 模型是一项绝对权

输出可访问
≠ 任何规模和方式的获取都正当

平台流量下降
≠ 智能体破坏竞争

形式上搭便车
≠ 已经扭曲竞争机制

最稳妥的判断单位始终是：具体行为 + 具体市场 + 具体损害 + 具体因果。
```

## 十、把学者放进一场能听懂的对话

### 第一轮：甲说“我投入这么大，乙凭什么白用”

- **蒋舸会先问：**专门知识产权规则为什么没有保护？既有图式是否已经表达了竞争自由的边界？
- **孔祥俊会补一句：**反法可以有限补充，但不能抵触专门法政策。
- **解亘会提醒：**一般条款可以进入评价，但不能从利益受损直接跳到救济。
- **孙山会换一个问法：**两部法保护的是不是不同法益？不要用“兜底”混在一起。

### 第二轮：甲说“乙这就是搭便车，不讲商业道德”

- **冯术杰会追问：**利用的是商誉，还是仅仅学习和竞争？消费者到底受到什么损害？
- **蒋舸会追问：**你说的行业惯例为什么合理，能否通过竞争效果检验？
- **孔祥俊会追问：**市场竞争机制具体在哪里被扭曲？

### 第三轮：乙说“我们根本不是同行”

- **吴伟光会回应：**不要只看商品是否可替代，要看双方是否争夺交易能力、注意力和用户选择。
- **但贾海东会加一道限制：**竞争关系可以宽认，真正决定模型利益空间的主营市场必须严认。

### 第四轮：法院说“那我综合衡量一下”

- **蒋舸会提醒：**先寻找成熟类型，别把开放衡量常态化。
- **侯利阳会建议：**先判断乙破坏的是甲的服务本身，还是只改变了甲的一种销售方式。
- **解亘会再问：**救济是否会让甲获得一项没有期限的准知识产权？

### 第五轮：把问题放进 AI 场景

- **贾海东会说：**从模型权益转向竞争损害，用技术、主营市场与因果关系限缩。
- **詹韫如会说：**蒸馏先分秘密获取与合法学习，搭便车不是自动违法。
- **冯晓青、张云蔚会说：**智能体冲击旧流量模式可能是创造性竞争；无授权、超权限和核心替代才需要重点审查。

## 十一、你真正需要记住的“三层共识”和“四个未决问题”

### 相对共识

第一层，**反法保护竞争，不是保护任何有价值的成果。**有投入、有价值、有损失，只能说明存在利益冲突，不能单独完成违法性证明。

第二层，**一般条款必须后置且谦抑。**具体知识产权规则、反法具体条款、合同和商业秘密能够处理时，应先用这些规则；一般条款不能用来躲避独创性、混淆、秘密性等门槛。

第三层，**抽象词必须转换成行为机制。**“搭便车”“商业道德”“干扰”“流量损失”都只是入口，最终要落到授权、技术措施、消费者选择、服务功能、市场替代和竞争秩序。

### 真正还没有解决的问题

1. **专门法沉默的含义如何查明？**哪些空白是立法者有意留给公众，哪些只是新技术尚未覆盖？
2. **功能标准如何证明？**竞争扭曲、消费者福利和交易成本需要什么证据，才能避免换一种抽象表达？
3. **数字服务中商品与销售方式如何二分？**广告、流量、数据和接口往往同时构成服务的一部分。
4. **AI 模型的累积替代阈值在哪里？**单次公开调用可能正当，但大规模蒸馏、自动交互和跨市场替代何时发生性质变化？

## 十二、拿到新案子时可以直接套用的口头分析顺序

不要一开始就说“构成／不构成不正当竞争”。按下面顺序讲，答案会自然长出层次：

```text
第一句：先准确描述行为，不使用“偷”“抄”“搭便车”等结论词。
第二句：检查知识产权、商业秘密、合同和反法具体条款。
第三句：说明专门法不适用究竟是沉默还是排除性评价。
第四句：找出被告相对于正常竞争多做的那一步。
第五句：把商业道德翻译成消费者、交易机会、系统功能或竞争机制损害。
第六句：尝试归入成熟行为类型，并说明相似和不同之处。
第七句：界定竞争关系与真正相关市场，不因跨界就放弃，也不因有联系就无限扩张。
第八句：检查授权、反向工程、转换性使用、公共利益和附属市场等阻却因素。
第九句：用比例救济只切掉不正当手段，避免创设准知识产权。
```

### 三个容易失分的表达

- 不说：“乙明显搭便车，所以违反商业道德。”
  - 改说：“乙确实利用了甲的既有投入，但仍须证明其取得方式或替代效果破坏了可识别的竞争机制。”
- 不说：“知识产权法不保护，所以反法兜底。”
  - 改说：“专门法不适用后，先辨明其立法政策；只有存在独立不正当因素时，反法才可能有限补充。”
- 不说：“双方不是同行，所以没有竞争关系。”
  - 改说：“直接同业并非必要，但应具体说明双方争夺何种交易能力、用户选择或市场机会。”

## 十三、30 秒、90 秒和 3 分钟口述

### 30 秒版本

一般条款与行为类型化的核心，是防止反不正当竞争法变成知识产权法败诉后的万能兜底。判断时应先尊重专门法边界，再寻找混淆、欺骗、破坏技术措施或实质替代等额外不正当因素，把“搭便车”“商业道德”翻译成可验证的竞争损害，最后用成熟行为类型和比例救济约束法官裁量。原告有投入、被告获益、原告受损，本身都不足以证明违法。

### 90 秒版本

这个专题首先处理知识产权法与反不正当竞争法的关系。蒋舸从认知经济性出发主张具体规则优先，解亘用“可能性兜底而非结果兜底”强调侵权法谦抑，孔祥俊提出不得抵触专门法政策的有限补充，孙山则以法益区分说明两法应平行保护。因此，专门法不保护并不自动触发一般条款。

第二步是判断不正当性。搭便车、违反商业道德或流量受损都不是结论。冯术杰强调消费者利益和竞争自由，孔祥俊强调竞争功能，蒋舸认为行业惯例只是信息中介。法院必须说明行为如何造成混淆、欺骗、技术妨碍、服务替代或竞争机制扭曲。

第三步是类型化。蒋舸要求围绕稳定变量建立高质量类型，而非罗列技术名词；侯利阳用商品与销售方式二分决定保护强度。到了 AI 场景，贾海东、詹韫如和冯晓青等人的共同方向，是从“模型有利益”转向“具体行为有无竞争损害”，并用主营市场、反向工程、授权范围和转换性使用限制保护。

### 3 分钟版本

我会用一个 AI 特效纠纷说明。甲平台开发照片变漫画模型，乙修图 App 通过公开输入输出调校出相似功能。甲会说自己投入巨大，乙搭便车并抢走用户。但法律不能从投入直接跳到违法。

第一，先查专门法。乙没有复制代码、取得参数或冒充甲，著作权、商业秘密和混淆条款可能都不直接成立。这时要问专门法的沉默是允许自由模仿，还是只没有覆盖乙的特殊手段。蒋舸强调具体规则作为成熟认知图式应当优先；解亘强调一般条款只有可能性兜底，不是结果兜底；孔祥俊要求补充保护不得抵触专门法政策；孙山则以法益区分反对两法重叠。共同点是不能因专门法不保护就自动改用一般条款。

第二，找行为增量。若乙只是从公开结果学习，形式上的搭便车还不够；若乙盗取密码、破解接触控制、欺骗用户或高频调用到使甲服务失灵，违法性才明显增加。商业道德也要功能化。孔祥俊会问竞争机制是否扭曲，冯术杰会问消费者是否被误导或选择受损，蒋舸会问所谓行业惯例是否真的降低交易成本，而不是头部平台自我保护。

第三，界定关系和类型。双方虽然一个做短视频、一个做修图，吴伟光会从交易能力和用户注意力承认广义竞争关系，但竞争关系宽认不等于责任宽认。侯利阳会进一步区分：乙若使甲服务本身无法运行，是商品类干扰；若只是减少广告和页面停留，则更像销售方式竞争，应有更高容忍度。蒋舸则提醒类型要围绕授权、技术措施、替代程度和消费者影响这些稳定变量，而不是“AI”“流量劫持”等名称。

第四，AI 场景还要设置三道阀门。贾海东要求检查基础或专业模型的技术属性、双方主营市场和法律因果关系；詹韫如把知识蒸馏分为不正当取得秘密与合法接触后的竞争性学习；冯晓青、张云蔚认为智能体减少平台流量可能是创造性竞争，只有超授权取数、滥用权限或实质替代核心服务时才重点介入。

所以最终结论不是“模型一律保护”或“模仿一律自由”，而是：一般条款只能针对具体不正当手段和可证明的竞争损害作有限救济，不能借此给甲创造一项控制模型效果、公开信息或商业模式的永久权利。
