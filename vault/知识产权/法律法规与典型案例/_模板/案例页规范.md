# 案例页命名规范与结构

本库为"法律条文"补充"对应案例"（指导性/公报/典型案例/地方典型等），用与司法解释相同的 Obsidian 双链挂接。

## 一、案例页存放
- 各域 `商标/专利/著作权/植物新品种/04-案例/` 存放本域法条所涉案例。
- 跨域共性案例（如惩罚性赔偿、管辖）放 `知识产权通用规则/04-案例/`。

## 二、文件名规范（案例页=一篇笔记，名称含案号或编号）
- **指导性案例**：`指导案例XX号-案由·案件名`（如 `指导案例XX号-侵害商标权·某某案`）。
- **入库案例（人民法院案例库）**：`入库案例YYYY-编号-案件名`。
- **公报案例**：`公报案例-案件名（案号）`。
- **地方法院/最高法典型案例**：`典型案例-案由·案件名（案号）`。
- 案号统一含全半角括号均可，但**避免 `/ \ : * ? " < > |`** 等 Obsidian/系统非法字符；用中文顿号、间隔号、全角括号。

## 三、frontmatter（案例页）
```
---
类型: 案例
类别: 商标                 # 商标|专利|著作权|植物新品种|共性
案例级别: 典型案例          # 指导案例|入库案例|公报案例|典型案例|地方典型|普通
案例编号:                 # 指导案例XX号 / 入库编号（如有）
案号: (2014)济民三初字第879号
法院: 山东省济南市中级人民法院
审级: 一审                # 一审|二审|再审
案由: 侵害商标权纠纷
裁判日期: 2015-07-03
当事人: 原告/上诉人/再审申请人…
对应法条: 商标法(2026)第72条   # 或 [[商标法#第七十二条]] 文本便于检索
状态: 草拟
来源: 知产宝 iphouse case 136579
---
```

## 四、正文结构（案例页要全）
1. `# 标题`（案件名 + 案号）
2. 案件基本信息（frontmatter 已列；正文可放一句导读）
3. `## 当事人` 
4. `## 基本案情` / `## 审理查明`
5. `## 裁判理由（本院认为）`
6. `## 裁判结果`
7. `## 裁判要旨 / 关联法条`（提炼裁判要点）
8. 回链：`## 关联法条` → `[[商标法#第七十二条]]`

## 五、法律页挂接样式
在《商标法》某条正文后的"对应区"新增一节：
```
> [!note] ⚖️ 对应司法解释／法规
> - [[商标民事纠纷解释#第九条]] …

> [!note] 📚 对应案例
> - [[典型案例-侵害商标权·拉菲案（2014济民三初字第879号）]]
> - [[指导案例XX号-…]]
```
法律页只放**案例名称链接**（不贴全文），点链接跳转到案例自己的页面看全文。
> 已采用样例：[[典型案例-拉菲罗斯柴尔德诉济南法莱雅侵害商标权案（2014济民三初879号）]]（对应 [[商标法#第七十二条]]）。

## 六、时效核对
取案例时须确认：所依据法律/司法解释为**现行有效版本**；被后续案例改判或已被更替规则的，标注"已不适用/仅历史参考"，不放现行案例区。

## 七、关于入库案例的说明
知产宝 iphouse 库**无独立的"人民法院案例库"索引**，仅能检索到"判决书正文引用了某入库案例"的普通文书，无法直接获取入库案例原文与编号。因此"入库案例"暂不单列，用指导/公报/典型案例代替；如需入库案例请另提供来源（如入库编号清单）。
