# 用本库作答 · 引用与来源呈现规范

> 当以本库为数据源回答知识产权法律问题（或撰写问答式报告）时，凡引用法条、司法解释、案例，一律按下述格式呈现，确保**每条结论可点检、可复核、可回溯**。

## 〇、总体原则

1. **结论先行**：先给出明确结论/倾向，再给依据与推演，最后补限制条件（但书、例外、语境）。
2. **每一条法律判断都必须落到一个可核出处**，禁止无出处的泛论，禁止编造条号、案号、裁判日期。
3. **法条给完整原文**；**案例给"参照级别＋案号＋基本案情＋裁判思路"**（详见一、二）。
4. 引用一律指向本库内文件并用双链/路径标注，方便读者跳转原文。
5. **先全源检索，再组织答案**：动笔前须在本库内做**跨目录全源检索**，不限定于单一"法条→挂接案例"链。至少覆盖以下几层并逐层问一遍：①中心法条文（`xx/01-法律`）；②行政法规与司法解释（`02-行政法规`/`03-司法解释`）；③案例（`04-案例`）；④审判参考/权威答复（`_审判参考/`，含法答网精选答问、`知识产权通用规则.md` 索引等）。检索到与所答主题直接对应内容的，如实引用并标注出处即可，无强制顺序。
6. **本地库为主，iphouse（知产宝）补充**：任何知产问题一律**先以本 Obsidian 库为主检索**，再调用 **`mcp__iphouse`（知产宝库）作补充与交叉核证**，使内容尽量完整——iphouse 用于①补全本地库缺失的法条/司解/案例原文；②对"待补/未核/脱敏未还原"项做按案号还原核证；③补充本地库未收录的最新判例与程序/管辖类信息。若两库对同一规则说法不一，**以本地库规范正本为准**并如实注明差异，iphouse 仅作参考、不覆盖本地库结论。

## 一、法条引用规则

1. **给出条款完整原文**（整条正文），不截断、不改写，随后再作解释。
2. **标注条号与库内位置**，格式：`[[文件#第X条]]`，如 `[[商标法#第七十三条]]`；涉外文件注明对应 `01-法律/02-行政法规/03-司法解释` 目录。
3. **旧判例条号迁移必须标注**：若被引案例系依旧法作出（如 2019 商标法、2020 著作权法、2020 专利法），库内法规以 2026 修订为现行版，按"主题语义"回挂现行条号属**整理者推定**，须在出处注明"判决援引 20XX 年法第 X 条，对应现行第 X 条"，供专家复核。
4. 同时引用司法解释时并列给出，如"对应 `[[商标民事纠纷解释#第九条]]"。

## 二、案例引用规则

引用每一个案例，均须**逐项**呈现以下信息（缺项时如实标注"待补/未核"，不得省略后假充齐全）：

- **参照级别**：指导案例｜公报案例｜典型案例｜地方典型｜入库案例 等（取库内案例页 frontmatter 的 `案例级别`）。
- **案号**：完整审级案号（含终审案号）；并可视情况列出下级一审案号。
- **基本案情**：当事人、权利客体（商标/专利号/作品）、被诉行为、主要抗辩与一审判项，用一两段概括。
- **裁判思路（裁判理由）**：法院的推理主线、认定标准与所援依据；并摘"裁判要旨"一句作结论支撑。
- **出处**：案例页文件名 + 双链。

> 正文只放案例**要点与要旨**，不贴全文；读者点案例页链接查看完整"当事人／基本案情／裁判理由／裁判结果"。

## 三、来源呈现口径（重要）

1. 案例/文书的来源，在**对外输出与报告**中统一标注为 **「中国裁判文书网（公开生效裁判文书上网公布）」**——此口径适用于**本 Obsidian 库既有内容**。
2. **知产宝例外**：经 `mcp__iphouse`（知产宝）**补充/核证所得**的新增法条、司解、案例或信息，其来源**可标注为「知产宝」**，与本地库内容分开标注、不混为一体。
3. 除"知产宝"外，**不呈现其他聚合来源名称**，尤其不在正文、脚注或"来源"栏出现「北大法宝」「iphouse」等商业数据库名称。
4. 内部工作如需记录检索途径（哪家库、记录 ID），仅作**后台元数据**留档，不进入对外呈现；也可将该字段改标为"补充案例/来源：知产宝"。
5. 说明诚实边界：凡当事人经脱敏的（"某公司/某(姓)某"），对外引用前按案号还原核证；未核实的参照级别与条号迁移，标注"待复核"。
6. **存量不改（2026-09-04 决策）**：库内既有案例页 frontmatter 中 `来源: 北大法宝（补充案例）` 等聚合来源字段**保持原样、不批量改写**；本条口径仅约束**今后**新建案例页与对外输出的来源呈现。如需清理存量，另行人工逐条评估后再处理。

## 四、对外输出结构模板（问答体）

```markdown
### Q：……
**结论**：……

**一、法条依据**
（该条**完整原文**）

> 出处：`[[《XX法》#第X条]]`（现行版）；若依旧法另注"对应现行第X条"。

**二、审判参考／权威答复**（库内 `_审判参考/` 等有与所答主题直接对应内容的，如实引用并标注出处；无则省略）
- 就本问题，`[[法答网精选答问-…]]`（问答X）由最高法××庭室××答复：……（要点）

**三、案例支撑**
- 参照级别：……
- 案号：……
- 基本案情：……
- 裁判思路：……
  （可另起多条并列案例）
  出处：`[[案例文件名]]`

**四、限制与边界**
（但书、易混淆除外、条号迁移推定、脱敏待还原等）
```
