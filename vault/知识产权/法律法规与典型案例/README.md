## 这套知识库的"做法"（核心方法论）

1. **定层级**：按法律位阶搭目录，一部源文件 = 一篇笔记。
2. **转结构化**：把 Word/PDF 抽成 Markdown，保住章/条/款结构。
3. **建双链**：每个法条下挂出"对应司法解释/法规"，写成 `[[文件#第X条]]`，可点跳。
4. **挂案例**：给关键法条挂权威案例（双向：案例页标关联法条，法条页列案例名）。
5. **校验生长**：用脚本全库查断链、坏锚点，随后续新规持续更新。

> 判断"这一条对应解释哪条、这个案例挂哪条"，本库用 AI 初拟 + 人工复核（"宁缺毋滥"）。**条号与对应关系仍以官方文本为准，使用前请人工核验。**

## 怎么用（Obsidian）

1. 用 Obsidian 打开本仓库目录即可（Obsidian 是免费的本地 Markdown + 双向链接笔记工具）。
2. 打开任一分域的中心法文件，如 `商标/01-法律/商标法.md`，点击某一条下方的"对应"链接即可跳转。
3. 阅读模式（而非编辑模式）下，`> [!note]` 卡片会显示为提示框。
