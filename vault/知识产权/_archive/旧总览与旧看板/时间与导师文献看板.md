# 时间与导师文献看板

## 一、总览：按年份倒序
适合先看某个老师近年在转向什么主题。

```dataview
TABLE teacher AS 导师, school AS 学校, trend_domain AS 上位领域, research_area AS 子议题, original_keywords AS 原文关键词
FROM "知识产权/papers"
SORT year DESC, teacher ASC
```

## 二、导师分组
适合申请前快速看每位导师“文章-领域-关键词证据”的组合。

```dataview
TABLE rows.year AS 年份, rows.file.link AS 论文, rows.trend_domain AS 上位领域, rows.research_area AS 子议题, rows.original_keywords AS 原文关键词
FROM "知识产权/papers"
GROUP BY teacher
SORT key ASC
```

## 三、年份分组
适合看每一年哪些导师在写哪些主题。

```dataview
TABLE rows.teacher AS 导师, rows.file.link AS 论文, rows.trend_domain AS 上位领域, rows.research_area AS 子议题
FROM "知识产权/papers"
GROUP BY year
SORT key DESC
```

## 四、导师-年份矩阵
需要开启 DataviewJS。适合一眼看出某位导师在哪些年份有文章、近年是否活跃。

```dataviewjs
const pages = dv.pages('"知识产权/papers"')
  .where(p => p.teacher && p.year)
  .array();

const years = [...new Set(pages.map(p => String(p.year)))].sort((a, b) => b.localeCompare(a));
const teachers = [...new Set(pages.map(p => p.teacher))].sort((a, b) => a.localeCompare(b, "zh-Hans-CN"));

dv.table(
  ["导师", ...years],
  teachers.map(t => [
    t,
    ...years.map(y => pages
      .filter(p => p.teacher === t && String(p.year) === y)
      .map(p => p.file.link)
      .join("；")
    )
  ])
);
```

## 五、导师-上位领域矩阵
需要开启 DataviewJS。使用九个统一上位领域，避免细关键词把矩阵横向撑得过宽。

```dataviewjs
const pages = dv.pages('"知识产权/papers"')
  .where(p => p.teacher && p.trend_domain)
  .array();

const teachers = [...new Set(pages.map(p => p.teacher))].sort((a, b) => a.localeCompare(b, "zh-Hans-CN"));
const areas = [...new Set(pages.map(p => p.trend_domain))]
  .sort((a, b) => a.localeCompare(b, "zh-Hans-CN"));

dv.table(
  ["导师", ...areas],
  teachers.map(t => [
    t,
    ...areas.map(a => {
      const matched = pages.filter(p => p.teacher === t && p.trend_domain === a);
      return matched.length ? `${matched.length} 篇` : "";
    })
  ])
);
```

## 六、近三年重点
适合判断近期 trend。当前资料中有些年份早于近三年，所以这里主要用于后续新增论文。

```dataview
TABLE year AS 年份, teacher AS 导师, trend_domain AS 上位领域, research_area AS 子议题, original_keywords AS 原文关键词
FROM "知识产权/papers"
WHERE number(year) >= 2024
SORT year DESC, teacher ASC
```

## 七、按学校筛选
清华与交大可以先分开看，避免不同学校的研究风格混在一起。

```dataview
TABLE year AS 年份, teacher AS 导师, file.link AS 论文, trend_domain AS 上位领域, research_area AS 子议题
FROM "知识产权/papers"
WHERE school = "清华大学"
SORT teacher ASC, year DESC
```
