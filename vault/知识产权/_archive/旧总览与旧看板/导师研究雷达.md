# 导师研究雷达

## 使用逻辑
主轴是“导师 -> 研究领域 -> 原文关键词证据”，不是“关键词 -> 论文”。

- `research_area`：根据论文题目、摘要、原文关键词和正文论证归纳出的研究领域。
- `trend_domain`：用于跨论文和跨年份比较的九个统一上位领域。
- `original_keywords`：只使用论文摘要后的原文关键词，用来支撑研究领域判断。
- `field`：部门法或交叉领域，例如著作权法、反不正当竞争法、人工智能法、数据法。

## 当前样张趋势判断
- 王迁：从“作品成立”入手讨论 AIGC 生成内容，关键词缺失，暂以主题和论证结构作为方向证据。
- 孔祥俊：集中在商业数据保护、数据权利、反不正当竞争法制度建构、商业道德标准和竞争秩序，显示其核心关切是开放性竞争法规则的类型化与可操作化。
- 曹博：集中在算法歧视、算法权力和规制范式，属于数字法治和算法治理。
- 崔国斌：集中在 AI 生成物、用户贡献、独创性、大数据有限排他权和网络爬虫治理，偏技术流程与市场结构中的权利边界判断。
- 蒋舸：集中在 AIGC、最低限度创造性、表达、理性无知、知识产权图式和一般条款边界，偏版权基础理论、解释论和裁判认知成本。
- 冯术杰：从商标恶意注册延伸到搭便车和商业标识保护，关注商标法与反不正当竞争法的体系边界。
- 吴伟光：从网络平台专有权、企业数据权益延伸到个人数据信息公共治理，关注数据权利客体和治理模式选择。

## 后续批量判断规则
- 先按老师聚合，不先按关键词聚合。
- 同一老师多篇论文的 `research_area` 重复出现，才判断为稳定研究方向。
- 原文关键词只作为证据：用于证明某个研究方向在论文中反复出现。
- 近三年论文权重更高，用于判断近期 trend。
- 如果一个老师从传统著作权、商标、竞争法转向 AIGC、数据、平台、算法，应在导师页写“研究迁移”。
- 每一批完成后同步更新交接文档：[[研究趋势/交接文档_继续整理知识产权论文|交接文档_继续整理知识产权论文]]
