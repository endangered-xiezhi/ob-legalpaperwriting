## 一句话主旨

平台从信息存储、信息交互演进为业务聚合生态圈后，相关市场和垄断关系随之扩张；传统反垄断法仍能处理平台间竞争，却难规制平台以市场组织权优待自营业务、压制独立商家，因而需要分类分级监管补位。

## 原文摘要

将平台视为固定形态导致我国的学术研究难以形成合力，即将开启的平台监管也举步维艰。平台已经从 Web 1.0 形态中的信息存储中介进化为 Web 2.0 形态中的信息交互中介、互联网生态圈形态中的业务聚合中介。平台形态的演变不但改变着平台的定义，也引发了平台垄断行为的扩张与异化，分别是 Web 2.0 形态与互联网生态圈形态对于相关市场界定的扩张，以及生态圈形态中平台与非竞争平台、商家关系的异化。虽然传统反垄断机制在引入平台形态演变的发展观后可以有效处理平台间的垄断行为，但无法应对平台与商家关系的异化，即平台利用市场组织职能强化市场盈利职能的相关行为。为弥补反垄断机制之不足，应当在区分平台类型的基础上设置分类监管，引导和监督大型平台内部规则的制定，禁止超级平台实施自我优待，并在扼杀性并购中采取举证责任倒置。

## 原文关键词

互联网生态圈；数字平台；双边市场；反垄断；监管。

## 通俗摘要

不同阶段的“平台”不是同一种企业：门户网站只存储信息，Web 2.0 平台连接商家与用户，生态圈平台则把多种业务和自营服务聚合起来。形态变化解释了为何早期研究集中在双边市场界定，后来研究转向独家交易、封禁、自我优待和扼杀性并购。作者主张，市场间竞争仍应坚持反垄断法的市场力量与效果分析；真正需要监管补位的是平台既当裁判又当运动员时对独立商家的结构性压制。

## 问题的提出

- 我国平台反垄断研究先后聚焦市场界定、垄断行为、反垄断与监管共治，但不同阶段结论冲突，原因在于把持续演进的平台当作固定形态。
- 文章依次追问：各阶段平台定义是否相同；集中讨论垄断行为反映了何种数字经济转型；哪些行为真正超出反垄断法能力并需要监管。
- 平台治理若不先区分形态，容易把体系内的市场界定难题误判为反垄断失灵，也可能用监管式逻辑超越反垄断法执法。

一句话概括：文章以平台进化史重新划定反垄断法能处理的竞争问题与监管应补充的结构性缺口。

## 问题的分析

- 三种平台形态
  - Web 1.0 是向单一用户群体单向展示的信息存储中介，竞争激烈且少有垄断问题。
  - Web 2.0 是连接商家与用户的信息交互中介，具有交叉网络效应、不均衡定价和平台内规则，首次形成大型平台与市场组织职能。
  - 互联网生态圈以核心业务聚合多种自研或并购业务，并利用平台数据进入商家市场，平台主体、职能和规模同时扩张。
- Web 2.0 的反垄断问题
  - 交易型双边市场围绕交易整体界定，非交易型双边市场则按行为作用的一侧分别界定；实践已能处理双边市场难题。
  - 平台为克服多宿主而实施独家交易、最惠国条款，仍可依传统合理原则审查市场封锁，不需要降低构成门槛。
  - 平台封号多是依据内部规则组织市场，原则上属于自我规制；超高定价与大数据杀熟亦未证明反垄断法体系失效。
- 生态圈的扩张与异化
  - 多业务聚合形成围绕核心平台业务的组产品市场；“腾讯封禁抖音案”显示原属不同业务的平台可能因生态圈竞争进入同一扩张市场。
  - 生态圈间自我优待和封禁需把对方核心平台的反制能力纳入竞争分析；支付宝口令突破微信封禁、顺丰与菜鸟互关接口表明割裂观察可能产生假阳性。
  - 生态圈内独立商家没有另一生态圈保护。平台可显性提高自营排序，也可利用商家数据隐性复制业务；传统差别待遇只禁止第三方之间歧视，必需设施门槛又很高，反垄断法难直接处理。
  - 扼杀性并购的损害在并购时难以证成，待创新被消灭后再执法又为时已晚。
- 对既有执法的批判
  - “阿里案”未充分量化封锁效果和反事实，“中国知网案”未充分比较价格与成本；以强化反垄断之名降低证明标准，会丧失反垄断法的谦抑与科学性。

一句话概括：两次市场范围扩张和平台对非竞争平台的异化仍可由反垄断法吸收，只有平台组织权与自营利益结合所造成的生态圈内失衡构成结构性缺口。

## 问题的解决

- 坚持反垄断法优先，只有出现结构性失灵才引入监管；平台间独家交易、最惠国条款、封禁等仍须证明市场力量与排除限制竞争效果。
- 围绕综合电商、搜索、社交、视频、即时通讯、操作系统、应用商店、支付、云计算等核心业务分类，不把所有平台业务都纳入监管。
- 设大型平台与超级平台两级：大型平台按用户规模和经济体量识别，超级平台只限竞争严重不足、生态圈内商家难靠转换平台自救的极少数场景。
- 对大型平台采用元规制：建立公开参与的平台规则制定程序、规则规划与外部督促、争议规则外部审查，并披露算法基本原则和风险。
- 对超级平台禁止无正当理由自我优待，但不全面禁止自营；对扼杀性并购由超级平台承担竞争效果的举证责任。

一句话概括：二元分治不是反垄断与监管并行扩张，而是以平台形态和结构性失灵为界，给大型与超级平台配置强度不同的补充义务。

## 应试启发

平台案先识别形态和竞争层次：Web 2.0 还是生态圈，平台间还是平台内。平台间案件仍按相关市场、支配地位、封锁效果、效率抗辩和反事实展开；平台内案件若涉及规则制定、自营优待、商家数据或扼杀性并购，再论证反垄断法差别待遇、必需设施和事后审查的局限，以及分类监管的必要性。
