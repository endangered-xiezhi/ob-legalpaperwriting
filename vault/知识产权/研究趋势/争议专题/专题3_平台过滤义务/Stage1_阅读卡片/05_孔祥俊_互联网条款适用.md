# 孔祥俊《"互联网条款"对于新类型网络服务的适用问题》

**作者**: 孔祥俊  
**副标题**: 从"通知删除"到"通知加采取必要措施"  
**资料来源**: 基于已有MD整理+部分TXT原文  

---

## 核心观点

1. **"互联网条款"需要扩张适用**：传统避风港条款无法涵盖新型网络服务，需要从"通知-删除"扩展到"通知+采取必要措施"
2. **新类型服务的特殊性**：链接、搜索、应用商店、云服务等新型服务在技术特征和侵权形态上与传统存储服务不同
3. **"必要措施"的灵活性**：应根据服务类型、技术能力、侵权情况确定具体措施，不限于"删除"
4. **注意义务的梯度配置**：不同服务类型应承担不同程度的注意义务

---

## 主要论据

1. **避风港条款的历史局限**：
   - 1998年DMCA制定时技术环境与现在差异巨大
   - 仅涵盖接入、缓存、存储、搜索四类服务
   - 新型服务（深度链接、应用商店、云服务）无法直接适用

2. **新型服务的责任困境**：
   - 微信小程序：一审认为类似接入服务，不适用通知-删除
   - 应用商店：断开链接是否足够？是否需要审查应用内容？
   - 云服务：切断服务造成不成比例负担

3. **"必要措施"的多元化**：
   - 删除/屏蔽内容
   - 断开链接
   - 停止服务
   - 技术过滤
   - 警示提醒
   - 具体措施取决于技术可行性和比例原则

4. **侵权责任法与信息网络传播权条例的协调**：
   - 《侵权责任法》第36条：通知+必要措施（归责条款）
   - 《信息网络传播权条例》：通知-删除（免责条款）
   - 适用关系：特别法优先，但应扩大解释

5. **比例原则的适用**：
   - 技术可行性：措施是否能够实现
   - 法律可行性：是否造成不成比例损害
   - 成本合理性：平台能否承受

## 重要案例

1. **微信小程序案**：一审认为类似接入服务，不适用"通知-删除"（杭州中院2019）
2. **应用商店案例**：向应用商店发出通知的界限问题
3. **阿里云案**：切断服务的不成比例负担
4. **深度链接案**：链接服务的特殊责任认定

## 争议点

1. **新型服务的类型化难题**：如何准确界定服务性质？
2. **"必要措施"的判断标准**：过于灵活是否导致不确定性？
3. **技术中立与责任加重的平衡**：如何避免过度限制技术创新？
4. **"通知-删除"vs"通知+必要措施"**：两套规则如何协调？

## 与AIGC专题关联

**关联度**: ⭐⭐⭐⭐

1. **生成式AI属于"新类型网络服务"**：
   - 不属于传统存储、搜索、链接服务
   - 需要通过扩大解释适用避风港条款

2. **"必要措施"在AI场景的适用**：
   - 删除内容：技术上困难（需重新训练）
   - 过滤提示词：效果有限，易被规避
   - 事后警示：可行但效果存疑
   - 算法调整：成本高但可能更有效

3. **注意义务的梯度配置**：
   - AI平台的特殊技术特征
   - "记忆"现象的不可控性
   - 商业模式与注意义务的关联

4. **从被动到主动的转变**：
   - 传统平台：通知后删除（被动）
   - AI平台：是否需要主动防范"记忆"？

## 研究价值

1. **理论创新**：提出从"通知-删除"到"通知+必要措施"的演进路径
2. **实践指导**：为新型网络服务的责任认定提供分析框架
3. **立法建议**：明确"必要措施"的判断标准和适用规则
4. **体系协调**：厘清《侵权责任法》与《信息网络传播权条例》的关系

**核心贡献**: 通过扩大解释"互联网条款"，将避风港规则适用于新型网络服务，同时通过"必要措施"的灵活性避免一刀切。
