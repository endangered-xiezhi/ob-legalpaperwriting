# 孙山《网络服务提供者版权内容过滤义务的"差序格局"配置》

**作者**: 孙山  
**期刊**: 《当代法学》2026年第4期  
**资料来源**: 已读TXT原文  

---

## 核心观点

1. **"差序格局"配置理念**：根据著作权人与网络服务提供者合作关系密切度，建构梯度化的过滤义务体系
2. **三类过滤义务**：事先免费提供比对作品的主动过滤义务、事后合格通知的被动过滤义务、特定情形的特别过滤义务
3. **合作共赢是核心**：过滤义务的引入首先是市场问题，其次才是法律问题
4. **反对一刀切**：避免欧盟式的"一般性监控义务"，主张灵活的梯度义务

---

## 主要论据

1. **"差序格局"理论的借用**：
   - 费孝通《乡土中国》：社会关系"一圈圈推出去，愈推愈远，也愈推愈薄"
   - 应用于过滤义务：合作关系密切度越低，约束力越弱
   - 符合比例原则：适当性、必要性、相称性

2. **合作关系密切度的核心地位**：
   - **前端成本**：比对作品数据库建设
   - **后端成本**：通知成本、审查成本、纠错成本
   - 合作关系越紧密，成本内部消化越多，执行成本越低
   - 成本降低到合理范围，过滤措施可转化为义务

3. **事先合作的主动过滤义务**：
   - **前提**：著作权人免费提供比对作品
   - **方式一**：著作权人上传已发表作品
   - **方式二**：用户生成内容平台约定免费授权使用
   - **货币化机制**：替代永久下架，实现多方共赢
   - **法律依据**：信息对称提高注意义务

4. **事后合作的被动过滤义务**：
   - **情形一**：著作权人发送合格通知+提供比对作品
     - 针对作品全部内容的主动过滤
     - 及时采取措施防止重复侵权
   - **情形二**：仅发送合格通知但不提供比对作品
     - 针对作品部分内容的被动过滤
     - 需要人工介入审核
     - 成本较高

5. **特别过滤义务**：
   - 著作权人未提供比对作品也未发送通知
   - 仅在特定情形出现时采取过滤
   - 成本最高，需人工审核代替算法

## 重要案例

1. **《庆余年》案**（重庆高院2024渝民终172号）：明确平台过滤、拦截技术措施必要性
2. **《梦华录》案**（重庆高院2024渝民终87号）：同上
3. **《长相思第一季》案**（重庆高院2025渝民终62号）：要求平台主动承担内容过滤义务
4. **YouTube Content ID系统**：事先合作+货币化的成功案例
5. **MySpace、Veoh与内容公司合作（2007）**：过滤机制的早期探索

## 争议点

1. **"差序格局"的适用争议**：
   - 社会学概念能否移植到法学？
   - 合作关系密切度如何量化？
   - 是否存在操作困难？

2. **免费提供比对作品的可行性**：
   - 著作权人是否愿意配合？
   - 格式转换成本谁承担？
   - 如何激励著作权人提供？

3. **货币化机制的合法性**：
   - 是否构成非法集体管理？
   - "转授权"的法律依据？
   - 如何保障著作权人权益？

4. **与欧盟模式的差异**：
   - 欧盟：一刀切的"一般性监控义务"
   - 中国方案：梯度化的"差序格局"
   - 哪种模式更优？

## 研究价值

1. **理论创新**："差序格局"概念的创造性应用
2. **体系建构**：三类过滤义务的系统设计
3. **实践导向**：以合作关系为核心的可操作方案
4. **本土化探索**：中国特色的过滤义务配置模式

**核心贡献**: 提出"差序格局"的过滤义务配置理论，以合作关系密切度为标准，建构梯度化、差异化的义务体系，为中国过滤义务立法提供创新方案。

**方法论特点**: 跨学科借鉴（社会学）+法教义学+实证分析+制度设计，视角独特，论证扎实。

**学术影响**: 2026年新作，代表最新研究成果，可能成为过滤义务研究的新范式。

**特别价值**: 对AIGC专题有重要参考价值，差序格局理念可直接应用于AI平台责任配置。
