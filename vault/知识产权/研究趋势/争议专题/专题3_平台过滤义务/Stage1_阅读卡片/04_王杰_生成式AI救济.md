# 王杰《生成式人工智能服务输出侵犯版权内容的救济研究》

**作者**: 王杰  
**期刊**: 《科技与出版》2024年第7期  
**资料来源**: 已读TXT原文  

---

## 核心观点

1. **角色定位**：生成式AI服务平台应界定为网络技术服务提供者，就侵犯版权适用过错责任
2. **拒绝"现有技术水平"标准**：该标准存在证成逻辑与义务内容上的缺陷，从产品责任借用不当
3. **拒绝安全保障义务标准**：公法义务与版权注意义务缺乏相关性
4. **"通知-删除"规则面临技术障碍**：大语言模型无法简单删除内容，需要重新训练成本极高
5. **救济应聚焦商业利用端**：个人利用可主张合理使用，商业利用可获更好救济并实现负外部性内部化

## 主要论据

1. **生成式AI平台的角色定位**：
   - 技术特征：根据用户提示词"即兴创作"，非事先存储
   - 教义学理由：平台无法控制大模型运算结果，缺乏控制不应视为直接提供
   - 法政策理由：快速迭代的新技术需要避免严格责任，防止阻碍发展

2. **"现有技术水平"标准之否定**：
   - 规范逻辑错位：将产品责任中的无过错标准用于过错责任判定
   - 实践不可操作：AI技术复杂且迅速迭代，行业标准难以确定
   - 标准高低两难：高标准抑制初创企业，低标准导致头部企业怠于改进

3. **安全保障义务标准之分析**：
   - 主体错位：将AI平台定性为内容提供者，与应承担过错责任矛盾
   - 义务内容不相关：
     - 《网络信息内容生态治理规定》针对低俗血腥，非版权
     - 《生成式AI管理办法》配合执法检查，非制止侵权
     - 显著标识义务是为提醒公众，非保护版权人
     - 风险提示义务实际效果存疑

4. **"通知-删除"规则的技术障碍**：
   - 技术不能：大语言模型非数据库，删除需重新训练成本高昂
   - 替代方案不可行：过滤"有问题"提示词无法预见具体表达，且易被规避

5. **"记忆"的风险与成因**：
   - 风险级别低：生成侵权内容概率仅0.03%，且多为思想相似
   - 成因分析：联结主义技术路线的不可控结果，非刻意为之
   - 易"记忆"情形：强视觉特征版权形象、训练语料中反复出现的图片、极受欢迎作品

6. **商业利用端救济的优势**：
   - 赔偿能力更强
   - 取证更容易（公开传播）
   - 版权人起诉私人不经济且易招怨恨
   - 促使平台通过合同调配权利义务（如微软Copilot的瑕疵担保）

## 重要案例

1. **广州互联网法院AI侵权案（2024年2月）**：全球首例生成式AI服务侵害著作权生效判决
2. **Getty Images诉Stability AI案**：演绎权主张难以成立，相似仅为思想层面
3. **美国针对AI的21件版权诉讼**（截至2024年3月）：主要涉及训练复制，2件涉及生成内容侵权
4. **Sony录像机案**："实质性非侵权用途"规则，技术中立的典范

## 争议点

1. **归责原则之争**：
   - 过错责任（王利明）vs 过错推定（周学峰）vs 无过错责任（徐伟）
   - 作者立场：过错责任，且AI开发者对"记忆"输出无过错

2. **注意义务标准之争**：
   - "现有技术水平"标准：借鉴产品责任，但逻辑不通
   - 安全保障义务标准：公法义务与私法责任混淆
   - "通知-删除"规则：技术上不可行

3. **合理使用的边界**：
   - 个人利用：为学习研究欣赏，构成合理使用
   - 商业利用：不合理损害版权人利益，应承担责任

4. **技术中立原则的适用**：
   - 索尼规则 vs 汉德公式
   - 联结主义vs符号主义技术路线
   - 可控性与责任的关系

## 与AIGC专题关联

**关联度**: ⭐⭐⭐⭐⭐（核心文献）

1. **直接针对AIGC输出侵权问题**：
   - 明确区分输入端（训练）与输出端（生成）的责任
   - 聚焦"记忆"现象的风险评估

2. **技术特征分析**：
   - 联结主义技术路线的不可控性
   - 大语言模型与传统数据库的本质区别
   - "即兴创作"特征对责任认定的影响

3. **救济路径创新**：
   - 商业利用端责任：区别于传统UGC平台的被动责任
   - 合同机制：平台承担"瑕疵担保责任"实现内部化
   - 私人使用豁免：合理使用在AI场景的适用

4. **政策考量**：
   - 技术中立原则的坚守
   - 避免抑制技术发展
   - 版权保护与技术创新的动态平衡

**关键贡献**: 系统论证了生成式AI平台不应承担输出侵权内容的过错责任，救济应转向商业利用端，为AI时代版权规则提供了新思路。

## 研究价值

1. **首次系统分析AI输出侵权的救济路径**：填补了AIGC版权研究的空白
2. **批判性检讨现有责任标准**：逐一否定"现有技术水平"和"安全保障义务"
3. **提出商业利用端救济方案**：兼顾版权保护与技术发展
4. **技术中立理论的延续**：将Sony规则应用于AI场景
5. **为立法和司法提供指引**：明确AI平台的角色定位和注意义务边界
