# 商业数据确权与反不正当竞争法保护：争议深化版

> [!summary] 核心判断
> 商业数据研究不是简单地从“不确权”走向“确权”，而是把单一所有权问题拆成**对象、公开状态、权源、持有与利用权能、获取使用行为、竞争损害和救济强度**。2025 年修订《反不正当竞争法》第 13 条第 3 款使研究进入现行法解释阶段：它保护经营者合法持有的数据利益，但要求不正当获取或使用、权益损害和竞争秩序扰乱，并未创设数据所有权。

> [!important] 证据边界
> 本页整合 [[研究趋势/争议专题/商业数据确权与反不正当竞争法保护|原争议专题]]、[[研究趋势/争议专题/商业秘密数字化、数据集合与算法透明|商业秘密数字化专题]]、[[研究趋势/面试专题/数据与商业秘密研究路径_面试表达版_2026-07-24|数据与商业秘密增量报告]] 以及本轮 51 篇新增论文。不同作者所称“数据权”“数据产权”“数据知识产权”并非同一概念，不能合并为统一确权论。

## 一、问题的提出：为什么“数据归谁所有”是一个过度压缩的问题

### 1. 数据同时具有六种使所有权类比困难的特征

- 可复制且复制后原持有人并不当然丧失使用；
- 同一数据可能由用户、设备、平台和加工者共同生成；
- 数据处于持续更新、组合和派生状态；
- 单条数据、集合、结构和产品的价值来源不同；
- 公开、有限共享和非公开状态可以动态变化；
- 数据利用还受个人信息、安全、跨境、开放和竞争义务限制。

### 2. 至少应分开七个问题

1. **对象**：保护单条数据、数据集合、数据产品、访问能力、平台结构还是模型？
2. **状态**：公开、有限共享、受控制还是完全非公开？
3. **权源**：来源者、持有者、加工者、产品经营者和数据主体分别贡献什么？
4. **权能**：持有、访问、加工、经营、许可、收益、排除不正当获取如何分配？
5. **行为**：独立采集、公开来源利用、反向工程、绕过措施、欺诈、胁迫和整体搬运有何差异？
6. **损害**：权益损害、产品替代、用户锁定、创新抑制和竞争秩序扰乱如何证明？
7. **救济**：禁止获取、限制用途、删除、赔偿、许可、开放或互操作应达到多强？

### 3. 四类数据对象不能共用一个保护强度

| 对象 | 主要利益 | 更可能的保护入口 |
|---|---|---|
| 原始／单条事实数据 | 来源、持有、人格或安全利益 | 个人信息、合同、数据安全、有限行为规制 |
| 非公开或有限共享的数据集合 | 重建成本、结构和实时性 | 商业秘密、合同、技术措施 |
| 公开数据形成的加工产品 | 组织、清洗、算法和经营利益 | 竞争法、合同、有限登记证据 |
| 平台、接口和访问能力 | 控制、组织和市场入口 | 平台规则、竞争法、反垄断与开放义务 |

## 二、学术谱系：从四种保护模型到权能—行为—救济分层

### 阶段一：2022—2023 年——四种保护模型竞争

#### 1. 商业数据弱权利／工业产权路径

[[论文库/商业数据权：数字时代的新型工业产权——工业产权的归入与权属界定三原则_孔祥俊|孔祥俊]]、[[论文库/论反不正当竞争法“商业数据专条”的建构——落实中央关于数据产权制度顶层设计的一种方案_孔祥俊|孔祥俊]]认为，商业数据凝结投入、可以交易，仅靠事后行为规制不足以形成稳定边界，可以构建有限、弱排他的数据权或专条。

#### 2. 商业秘密吸收路径

[[论文库/新酒入旧瓶：企业数据保护的商业秘密路径_崔国斌|崔国斌]]通过单条／集合、公开状态、替代成本和合理措施重构商业秘密，强调既有制度能够保护非公开企业数据，同时保留独立开发和反向工程。

#### 3. 平台专有权路径

[[论文库/通过网络平台专有权实现对企业数据权益的保护_吴伟光|吴伟光]]认为数据本身难以特定和公示，可将承载、组织并控制数据的平台作为权利对象。

#### 4. 竞争行为规制路径

该路径不先承认对数据的一般排他，而审查抓取来源、访问权限、技术措施、使用方式和竞争损害。

### 阶段二：2024—2025 年——弱权利与行为规制相互靠近

- 支持专条者开始强调弱排他、合法来源、用途和流通限制；
- 反新增权利者承认合法持有、加工和产品经营可以形成可保护利益；
- 商业秘密路径进一步区分公开数据、集合秘密性和反爬措施；
- 数据知识产权登记进入交易、证据和公示讨论。

争议由“有没有权”推进到“何种权能、对抗何种行为”。

### 阶段三：2025—2026 年——法条适用与司法案例

2025 年修订《反不正当竞争法》第 13 条第 3 款规定，经营者不得以欺诈、胁迫、避开或破坏技术管理措施等不正当方式，获取、使用其他经营者合法持有的数据，损害其合法权益并扰乱市场竞争秩序。

[[论文库/反不正当竞争法数据保护专款的司法适用研究_徐俊|徐俊]]、[[论文库/新反不正当竞争法中平台用户数据保护的法律适用研究_林新宇|林新宇]]、王磊等研究将重点推进到：

- “合法持有”的权源；
- 不正当方式的开放性；
- 获取与使用是否都要求手段不正当；
- 权益损害与竞争秩序的关系；
- 专条与一般条款、商业秘密条款的竞合；
- 救济是否会产生事实排他。

### 阶段四：2026 年 7 月增量——权能分置、登记与开放反向校准

- 梅夏英的控制论、张素华的结构性分置、王年的来源者权、吕炳斌的公开换权利，使“确权”内部进一步分化。
- 邵红红将登记定位为交易信号，吕炳斌强调数据库式公开，潘柏华强调分级公示。
- 侯利阳以公开／非公开配置强弱保护；曹新明、叶悦区分商业数据专条与商业秘密。
- 数据可携、互操作、必需数据开放、访问权质押、重要数据和跨境安全表明，保护并非唯一政策目标。

研究范式最终转向：**权能分置＋状态分层＋行为规制＋比例救济＋开放校准**。

## 三、争议板块一：数据是否适合成为统一排他权客体

### 1. 支持客体化的理由

- 交易需要明确的许可主体和权利边界；
- 数据采集、清洗、标注和产品化需要投资回收；
- 行为法事后判断降低可预期性；
- 标准化数据产品可以编号、登记并持续许可；
- 弱权利可通过期限、例外和用途限制避免所有权化。

### 2. 反对统一客体化的理由

- 同一数据可由多个主体合法产生或持有；
- 数据可复制、动态变化，难以公示边界；
- 原始数据、集合、产品和平台控制不是同一对象；
- 排他权可能造成许可层叠和数据反公地；
- 个人信息、公共数据和重要数据不能仅按财产权处理；
- 既有合同、商业秘密、知识产权和竞争法可以组合保护。

### 3. “数据权”内部至少有四种不同含义

| 方案 | 保护中心 | 对第三人的效果 |
|---|---|---|
| 事实控制 | 现实持有和访问能力 | 原则上不当然产生对世排他 |
| 权能分置 | 持有、加工、经营等利益束 | 各权能可由不同主体享有 |
| 来源者权 | 数据生成和来源贡献 | 可能形成参与分配或控制利益 |
| 公开换权利 | 登记／公开后获得有限保护 | 以公示对价换取可识别弱权利 |

不能把这四种方案都概括为“支持数据所有权”。

### 4. 综合判断

现阶段更适合将数据保护理解为：

- 对特定数据状态的合法控制利益；
- 对加工、产品化和经营形成的可保护利益；
- 对不正当获取使用的排除权能；
- 对访问、加工、许可和收益的可分配权能；

而不是对数据事实内容的一般、永久、排他的所有权。

## 四、争议板块二：数据权能如何在多主体之间分置

### 1. 主要参与者

- 数据所关联的个人；
- 生产经营活动中的来源者；
- 设备和系统运营者；
- 合法持有和控制者；
- 清洗、标注、聚合和分析者；
- 数据产品经营者；
- 获得许可的下游使用者；
- 承担公共管理职责的国家机关。

### 2. 权能分置的核心

| 权能 | 主要内容 | 可能限制 |
|---|---|---|
| 持有 | 保存和现实控制 | 安全、个人信息、返还义务 |
| 访问 | 进入系统、接口或数据集 | 权限、技术措施、开放义务 |
| 加工使用 | 清洗、分析、组合、训练 | 目的限制、合同、知识产权 |
| 产品经营 | 对加工产品提供服务和交易 | 数据来源、竞争与消费者利益 |
| 许可／收益 | 允许下游利用并分配价值 | 多主体权源、强制性规范 |
| 排除不正当获取 | 制止窃取、欺诈、绕过措施 | 不及于公开来源、独立开发和合理获取 |

### 3. 多源数据的难题

同一数据产品可能包含：

- 用户行为；
- 平台系统记录；
- 第三方数据；
- 公共信息；
- 企业加工规则；
- 算法推导结果。

单一主体排他权难以说明各贡献的优先顺位。权能分置的优势在于允许并行利益，但仍需解决：

- 谁可以对外许可；
- 下游如何确认权源；
- 收益如何分配；
- 某一主体撤回或限制是否影响整体产品；
- 善意第三人是否获得保护。

## 五、争议板块三：数据知识产权登记究竟产生什么效力

### 1. 设权理解的吸引力

登记证书看似能够：

- 特定数据客体；
- 标明主体和形成时间；
- 支持交易和融资；
- 降低诉讼举证成本；
- 形成公开权利边界。

### 2. 登记直接设权的困难

- 地方试点规则和证书效力不统一；
- 登记机构通常不进行完整实体审查；
- 数据持续更新，登记内容可能迅速变化；
- 多源权利和个人信息难以由申请人单方确认；
- 公开登记可能破坏商业秘密；
- 第三人无法仅凭摘要判断具体边界。

### 3. 四层登记功能

1. **时间证明**：数据集或产品在特定时间已经形成。
2. **来源和结构说明**：记录数据类别、加工规则、版本和样本。
3. **交易信号**：向交易相对人显示持有状态、合规文件和可许可范围。
4. **初步证据**：诉讼中形成可反驳推定，但允许第三人以真实来源、在先持有和独立开发反证。

### 4. 分级公示

| 公示层级 | 内容 |
|---|---|
| 公众层 | 名称、摘要、类别、版本、登记主体和时间 |
| 交易层 | 来源说明、加工方式、许可范围和限制 |
| 监管／司法层 | 更完整的数据样本、合规材料和权源文件 |
| 保密层 | 核心结构、非公开样本和算法，仅在受控条件下访问 |

### 5. 综合判断

登记更适合成为**有限公示＋交易信号＋可反驳初步证据**，而不是当然产生对全部数据内容的全国统一排他权。

## 六、争议板块四：商业秘密与数据专条如何分工

### 1. 商业秘密适用的优势

- 已有秘密性、商业价值和合理措施要件；
- 保护非公开和有限共享信息；
- 以不正当获取、披露、使用为中心；
- 明确保留独立开发和反向工程；
- 可保护数据集合、结构、参数和实时关联。

### 2. 商业秘密的边界

- 完全公开数据通常不满足秘密性；
- 高整理成本不能把公众信息自动重新封闭；
- 权利人未采取合理措施时不能事后追认秘密；
- 数据来源和个人信息合规仍须独立判断；
- 集合秘密性不能吞没单条公开数据的自由状态。

### 3. 数据专条的功能

数据专条适合处理：

- 数据不完全满足商业秘密要件；
- 行为采用欺诈、胁迫、绕过或破坏技术管理措施；
- 获取或使用损害合法持有者权益；
- 行为进一步扰乱市场竞争秩序。

### 4. 两条路径不能降格替代

若数据实际主张为非公开秘密，却无法证明合理措施，不宜仅因商业秘密要件失败就自动适用数据专条。否则会架空秘密性边界。

相反，公开数据即使不构成秘密，若被告盗取密钥、破坏访问限制或通过欺诈取得，仍可能进入数据专条。

### 5. 分流表

| 数据状态／行为 | 主要路径 |
|---|---|
| 非公开＋合理措施＋不正当获取 | 商业秘密优先 |
| 有限共享＋接收者明知保密 | 商业秘密／合同 |
| 单条公开、集合结构未公开 | 先审集合秘密性和措施 |
| 完全公开＋合法独立采集 | 原则自由利用 |
| 公开数据＋欺诈、破坏措施取得 | 数据专条 |
| 公开数据＋合法采集并加工产品 | 原则允许，另保护加工者经营利益 |

## 七、争议板块五：2025 年新法第 13 条第 3 款的要件

官方文本：[中国人大网](https://www.npc.gov.cn/npc/c2/c30834/202506/t20250627_446247.html)。

### 1. 主体与场景

条文位于网络不正当竞争规定中，原则上要求经营者利用网络从事生产经营活动。需要说明被告的经营者身份、竞争活动及境内竞争秩序联系。

### 2. 他人合法持有的数据

“合法持有”至少要求：

- 数据来源或取得方式合法；
- 持有不违反个人信息、数据安全或其他强制性规范；
- 原告对数据具有现实控制、加工或经营利益；
- 不能仅以服务器存储或事实占有证明全部权益。

### 3. 不正当获取或使用

法条列举欺诈、胁迫、避开或破坏技术管理措施，并以“等不正当方式”保持开放。解释时应避免：

- 只因未经同意就认定不正当；
- 只因竞争者获益或原告投入就认定不正当；
- 把违反平台单方规则自动等同违法；
- 忽略公开来源、独立开发和用户自主授权。

可以重点识别欺骗身份、滥用接口权限、盗取密钥、突破频率限制、破坏认证、利用内部关系和超越授权目的。

### 4. 合法权益损害

应说明受到损害的是：

- 数据持有、加工或经营利益；
- 数据产品市场；
- 技术控制和安全利益；
- 用户关系或服务质量；
- 投资回收机会。

单纯证明被告节省成本或原告不满，通常不足。

### 5. 竞争秩序扰乱

需要进一步说明：

- 行为是否通过非效能手段取得竞争优势；
- 是否实质替代原数据产品；
- 是否降低创新和数据生产激励；
- 是否造成用户锁定、市场封锁或动态竞争损害；
- 是否损害消费者、交易相对人或数据流通。

权益损害与竞争秩序不能完全合并为一个结果。

### 6. 救济比例

即使构成不正当竞争，也应区分：

- 禁止继续以特定手段获取；
- 禁止特定超范围用途；
- 删除不当取得的数据副本；
- 赔偿实际损失或不当收益；
- 允许从合法来源重新取得；
- 不禁止独立开发和合理公开来源利用。

## 八、争议板块六：指导性案例 264 号的规范意义

官方案例：[最高人民法院](https://www.court.gov.cn/zixun/xiangqing/474471.html)。

### 1. 案例区分的三层利益

- 钢铁企业对经营中产生的出厂价格享有持有、使用等利益；
- 公开价格不能被原企业用于禁止他人合法合理采集；
- 数据处理者通过合法采集、合规方法形成价格指数，对数据产品享有经营利益。

### 2. 案例否定的三种推论

- 数据由企业产生，不等于企业可以禁止一切采集；
- 合作合同终止，不等于原本合法公开来源随之变成非法；
- 数据处理者有经营利益，不等于其拥有原始价格数据。

### 3. 对未来案件的启示

应按数据来源和生成特征分配不同利益，并分别审查：

- 数据是否公开；
- 采集方式是否合法；
- 加工方法是否符合标准；
- 数据产品质量是否造成损害；
- 原持有者的使用是否被剥夺；
- 是否存在不正当竞争手段。

## 九、争议板块七：平台控制、可携与必需数据开放

### 1. 平台专有权的贡献

平台比抽象数据更容易识别、控制和公示，可以解释：

- 谁维护数据基础设施；
- 谁承担安全责任；
- 谁能授权接口和访问；
- 谁对平台空间投入。

### 2. 平台专有权的局限

- 数据可以跨平台流动；
- 用户对自身数据享有携带和控制利益；
- 多平台可能共同生成相同数据；
- 平台控制可能形成锁定、拒绝交易和自我优待；
- 强制互操作会改变封闭平台边界。

### 3. 数据可携

可携权不是简单把平台数据“还给用户”，而涉及：

- 可携对象是用户提供数据、观察数据还是推导数据；
- 接收平台的安全和责任；
- 第三人信息和商业秘密；
- 实时、机器可读和互操作标准；
- 是否形成持续访问而非一次复制。

### 4. 必需数据开放

强制开放至少应审查：

- 数据是否真正不可替代；
- 请求者能否自行生成或从其他来源取得；
- 平台是否具有市场支配力或关键控制；
- 开放是否损害隐私、安全和创新；
- 访问条件、价格、用途和审计如何配置。

保护与开放不是逻辑矛盾，而是不同条件下对不同权能的配置。

## 十、相对共识、真正未决问题与压力测试

### 1. 相对共识

- 数据不宜简单归入单一所有权。
- 合法持有、加工和产品经营可以形成不同利益。
- 投入证明利益存在，不单独证明对手违法。
- 公开数据原则上应保留合法采集和合理利用。
- 非公开或有限共享数据集合可优先适用商业秘密。
- 数据登记主要具有证明、信号和交易功能。
- 新法第 13 条第 3 款是行为规制，不是确权条款。
- 数据保护必须接受可携、开放、安全和公共利益校准。

### 2. 真正未决问题

1. “合法持有”需要何种权源和合规证明？
2. 新法中的“使用”是否也必须通过不正当方式取得？
3. 竞争秩序扰乱能否由权益损害推定？
4. 地方登记证书在跨区域诉讼中具有何种证据效力？
5. 有限共享数据的秘密性边界如何确定？
6. 多源数据产品的许可和收益如何分配？
7. 数据专条与商业秘密、一般条款如何竞合？
8. 必需数据开放是否以市场支配地位为前提？

### 3. 压力测试

| 新事实 | 首先承压的观点 | 原因 |
|---|---|---|
| 数据产品标准化、编号并持续许可 | 以不可特定否定一切客体化 | 识别和交易成本下降 |
| 多平台合法生成同一用户数据 | 单一主体排他权 | 权源和优先顺位重叠 |
| 强制可携与互操作 | 平台专有权 | 封闭控制不再稳定 |
| 竞争者从公开来源独立重建 | 投入型保护 | 投入不能禁止合法替代 |
| 盗取密钥整体搬运实时数据库 | 纯公开自由论 | 获取手段和控制利益明显不正当 |
| 登记仅形式审查且数据持续变化 | 登记即确权 | 权利真实性和边界不稳 |

## 十一、解释论方案：建议采用“七要素＋三层保护”

### 七要素

1. 对象；
2. 公开状态；
3. 权源；
4. 权能；
5. 获取／使用行为；
6. 权益与竞争损害；
7. 救济强度。

### 三层保护

#### 第一层：状态

公开、有限共享、非公开决定商业秘密、合同或行为法入口。

#### 第二层：行为

区分合法来源、独立开发、反向工程与欺诈、胁迫、权限滥用、绕过或破坏措施。

#### 第三层：救济

只禁止与不正当行为和损害相对应的获取使用，为合法重新取得、独立开发、可携和必要开放保留空间。

## 十三、面试问题模块

### 1. 基础问题

1. 是否应确立数据所有权？
2. 数据权能分置是什么意思？
3. 数据知识产权登记是否等于确权？
4. 公开数据能否构成商业秘密？
5. 新《反不正当竞争法》数据条款有哪些要件？
6. 数据专条与商业秘密如何分工？
7. 平台是否应对其控制的数据享有专有权？
8. 数据可携和必需数据开放是否损害数据产权？

### 2. 30 秒回答

> 我不会先问数据归谁所有，而会审查对象、公开状态、权源、权能、获取使用行为、竞争损害和救济强度。非公开且采取合理措施的数据集合可以进入商业秘密；公开数据原则上保持可利用，只有欺诈、胁迫、绕过措施等不正当获取使用并造成权益和竞争秩序损害时，才进入新法数据条款。登记主要是有限公示、交易信号和可反驳初步证据，不是当然确权。

### 3. 90 秒回答

> 商业数据研究已经从四种抽象保护模型进入权能分置和现行法解释。弱权利路径解决交易确定性，商业秘密路径保护非公开集合并保留独立开发，平台路径强调控制和公示，行为法则防止排他过度。我主张采用七要素和状态—行为—救济三层模型：先区分单条数据、集合和产品及其公开状态，再识别来源者、持有者和加工者的不同权能；责任层面严格审查不正当获取使用、权益损害和竞争秩序，最后只给予比例救济。新法第 13 条第 3 款不是数据所有权条款，指导性案例 264 号也表明公开企业数据可以被合法采集加工。登记可以降低证明和交易成本，但应允许真实来源、在先持有和独立开发反证。

### 4. 3 分钟展开顺序

1. 说明所有权问题为什么过度压缩；
2. 报告弱权利、商业秘密、平台专有权和行为法四条路径；
3. 解释权能分置和数据对象分层；
4. 讨论登记的四层功能；
5. 解释商业秘密与数据专条分流；
6. 展开新法五项要件和指导性案例 264 号；
7. 加入可携、开放和比例救济；
8. 提出七要素＋三层保护模型。

### 5. 高频追问

**问：没有所有权，数据怎么交易和融资？**

> 交易可以围绕合法持有、访问、加工、许可和收益权能展开，并通过合同、登记、审计和担保结构降低风险，不必以统一所有权为前提。

**问：企业投入很大，为什么不能排除公开数据的竞争者？**

> 投入证明经营利益和激励需求，但公开信息原则上可被合法采集。只有不正当获取、直接产品替代或竞争秩序损害达到法定门槛时，才产生相应救济。

**问：登记证书为什么不能确权？**

> 地方登记通常不进行完整实体审查，数据还会持续变化并包含多源权利。证书更适合作为形成时间、来源和结构的初步证明，并允许反证。

**问：商业秘密保护不了公开数据，数据专条是否自动适用？**

> 不自动。仍须证明不正当获取或使用、合法权益损害和竞争秩序扰乱，不能把秘密性失败降格转化为行为法保护。

### 6. 容易失分的表达

- 不说“数据二十条已经确立数据所有权”。
- 不说“企业投入形成的数据当然属于企业”。
- 不说“合法持有就是排他权”。
- 不说“数据登记证书就是产权证”。
- 不把商业秘密要件失败自动转为数据专条责任。
- 不把新法第 13 条第 3 款简化成“未经同意使用数据”。
- 不忽略个人信息、数据安全、可携和开放义务。
