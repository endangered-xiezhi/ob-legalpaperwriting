# 大模型训练数据的复制权、合理使用与许可：争议深化版

> [!summary] 核心判断
> 训练数据争议已经从“合理使用还是许可”的单点冲突，发展为一条完整的规范链：**数据来源是否合法—各技术阶段是否落入复制权—权利限制或许可如何分层—透明、退出和付酬如何执行—证据偏在与机器遗忘如何处理**。任何跳过前一层、直接回答“训练合法／违法”的方案，都容易把不同问题混成一个结论。

> [!important] 证据边界
> 本页整合 [[研究趋势/争议专题/大模型训练数据的复制权、合理使用与许可|原争议专题]]、[[研究趋势/面试专题/著作权AI与商标法研究路径_面试表达版_2026-07-23|著作权 AI 与商标法增量报告]] 及库内训练数据论文。技术过程因模型架构而异，下文的阶段划分是规范分析工具，不意味着所有模型都实施完全相同的复制行为。

## 一、问题的提出：为什么不能只问“训练是否构成合理使用”

### 1. 至少存在六个前后相接的问题

1. **来源合法性**：公开网页、授权数据库、绕过措施、泄露数据和用户上传材料的评价不同。
2. **技术行为**：抓取、下载、缓存、清洗、分词、向量化、训练、权重形成和训练集保存不能合并。
3. **权项构成**：形成技术副本是否已满足复制权，还是还需表达再现、传播或公众接触风险？
4. **限制与许可**：合理使用、TDM、法定许可、集体管理、选择退出和个别授权如何分工？
5. **市场影响**：原作消费、训练许可市场、风格市场、输出替代和模型竞争属于不同市场主张。
6. **证明与救济**：由谁说明来源，退出能否执行，停止侵害是否必须删除或重训模型？

如果前端行为不进入复制权，通常无须讨论合理使用；如果来源本身违法，统计学习目的也不能自动洗白；如果侵权成立，删除训练文件不一定足以消除模型影响。

### 2. 三种容易误导的整体化表述

- “训练只是学习思想”：忽略下载、缓存和训练库可能保留表达。
- “训练必然复制，所以必须许可”：忽略复制权的功能边界、非表达性用途和权利限制。
- “模型不会保存原作，所以没有损害”：忽略前端获取、训练许可市场及高概率复现。

### 3. 事实场景应先类型化

| 场景 | 规范风险 |
|---|---|
| 公共领域、合成或明确授权数据 | 来源风险低，重点转向许可范围和输出 |
| 合法访问的公开网页，未绕过措施 | 争议集中于复制权、权利保留和合理使用 |
| 付费数据库、明确禁用或访问受限内容 | 合同、技术措施和来源正当性风险上升 |
| 泄露、盗取或绕过技术措施取得 | 前端违法具有独立意义 |
| 训练集长期保存且可检索原作 | 已不只是统计学习，表达接触和传播风险上升 |
| 模型高概率复现训练作品 | 输入端非表达性论证和市场无替代论承压 |

## 二、学术谱系：争议如何从 TDM 豁免扩展为全生命周期治理

### 阶段一：2019—2022 年——以复制＋豁免为基本结构

早期研究通常承认文本和数据挖掘会形成大量技术复制，核心问题是：

- 能否解释进现有合理使用条款；
- 是否应增设计算机信息分析或科研 TDM 例外；
- 商业训练是否应被排除；
- 三步检验能否作为开放条款使用。

此阶段多把“发生复制”作为共同前提，争议主要落在豁免范围。

## 三、争议板块一：训练中的技术复制是否落入复制权

### 1. 传统固定复制路径

**论证链条**：

1. 下载、缓存、清洗和长期存储形成可识别、相对稳定的副本；
2. 复制权构成不以向公众传播或以欣赏为目的为必要；
3. 非表达性目的应在合理使用层处理，而不是倒置到构成要件；
4. 否则会通过技术目的限缩法定权项。

**优势**：符合数字复制的通常文义，保留权利限制的体系位置。

**难点**：若任何瞬时技术固定都进入复制权，权利范围可能覆盖几乎所有机器处理，造成过度许可。

### 2. 非作品性使用／不构成复制路径

**论证链条**：

1. 模型训练旨在提取统计规律、概念和概率关系；
2. 训练完成后通常不向公众提供单项原作；
3. 著作权不应控制思想、事实和非表达性分析；
4. 因而部分阶段不进入复制权，或即使有技术副本也不属于权利应控制的风险。

**优势**：避免复制权覆盖所有计算过程，保护知识学习与技术创新。

**难点**：实际训练前端可能完整下载作品，训练集还可能长期保存、检索和复用。以最终目的概括全部阶段，会掩盖独立复制行为。

### 3. 复制权功能重构路径

该路径试图在两端之间增加功能标准：

- 施小雪强调固定性与传播性；
- 涂藤强调公众接触原表达的高度盖然性；
- 李春晖强调训练过程是否形成著作权法意义上的表达再现。

**主要争点**：这些标准是复制权构成的应有解释，还是把合理使用、市场损害因素提前纳入侵权构成？

### 4. 综合判断：按阶段和副本功能区分

| 阶段／状态 | 评价重点 |
|---|---|
| 瞬时流式读取且无可还原副本 | 固定性、可再现性较弱 |
| 下载、缓存和预处理形成完整文件 | 复制构成风险较高 |
| 向量化后不能还原表达 | 需区分中间副本与向量本身 |
| 训练集长期保存且可检索 | 独立数据库和传播风险上升 |
| 权重可高概率输出原作 | 可反向支持具体表达被吸收的事实推论，但不当然证明每次训练侵权 |

## 四、争议板块二：来源合法性在著作权判断中的位置

### 1. 来源违法不是单纯外围问题

绕过访问控制、使用盗版库、泄露材料或违反明确权限，可能同时触发：

- 著作权侵权；
- 技术措施保护；
- 合同责任；
- 商业秘密；
- 反不正当竞争法数据条款；
- 个人信息和数据安全规范。

即使最终统计学习属于非表达性用途，前端不正当获取仍须独立评价。

### 2. 公开可访问不等于默示授权

公开网页至少可能存在四种不同状态：

1. 完全公开且无机器可读保留；
2. 公开但有明确禁用声明；
3. 对人公开但对自动抓取设置技术限制；
4. 仅向付费、注册或特定群体开放。

“能访问”只说明事实可得，不当然说明授权；反过来，单纯格式化声明是否足以创造法外复制禁令，也需结合现行法、技术措施和合同成立审查。

### 3. 来源合法性如何进入合理使用

可以采取两层处理：

- **独立违法层**：窃取、绕过措施、违反访问权限等本身承担责任；
- **合理使用衡量层**：来源违法削弱使用者的善意、必要性和利益平衡，但不把任何合同违约自动升级为著作权侵权。

这样既不让训练目的洗白违法来源，也不让平台单方条款无限扩张著作权。

## 五、争议板块三：合理使用、TDM 与条件矩阵

### 1. 原则合理使用的主要理由

- 训练多为非享受性或非作品性利用；
- 单项作品对模型性能的边际贡献难以识别；
- 海量逐项授权可能形成反公地；
- 训练促进技术创新和新表达；
- 输出端可以独立规制复现与替代。

### 2. 反对全面合理使用的主要理由

- 我国《著作权法》第 24 条列举结构缺少明确商业 TDM 条款；
- 商业模型直接利用作品价值并形成可交易产品；
- 训练许可市场正在形成；
- 来源违法、规避技术措施和权利保留会削弱善意；
- 过拟合、记忆和输出替代可能损害现实市场；
- 全面豁免会把创作者排除于价值分配之外。

### 3. 六维条件矩阵

| 变量 | 倾向较宽空间 | 倾向授权／付酬或较严责任 |
|---|---|---|
| 来源 | 公共领域、授权、合法公开 | 盗版、泄露、绕过措施 |
| 目的 | 科研、公共利益、内部分析 | 大规模商业通用模型 |
| 数据形态 | 分散数据、单项贡献低 | 策划数据库、私人定制、高价值库 |
| 权利保留 | 无明确保留或已尊重退出 | 明确机器可读保留仍规避 |
| 输出风险 | 不可识别、低复现、低替代 | 过拟合、高复现、同一市场替代 |
| 许可条件 | 市场不存在、成本极高 | 许可基础设施成熟且不排除小主体 |

### 4. 我国第 24 条的解释边界

面试和论文中应分别回答：

1. 训练能否进入现有列举目的；
2. 三步检验是解释工具还是独立开放条款；
3. 商业性是否决定性；
4. 新形成的训练许可市场应获得多大权重；
5. 是否需要立法增设 TDM，而不是完全依赖司法扩张。

较稳妥的立场是：在现行列举结构下，不宜用抽象“转换性”创设无限商业豁免；但可通过阶段切割、来源和市场类型化，为低替代、合法来源利用保留解释空间，并推动明确的 TDM 或报酬规则。

## 六、争议板块四：许可、退出与付酬机制

### 1. 个别授权

适合高价值、可识别、权利集中或私人定制数据，但无法覆盖海量开放网络语料。

### 2. 法定许可

**优点**：避免逐项拒绝造成训练堵塞，同时让权利人分享收益。

**难点**：费率、分配、适用主体、国际作品、孤儿作品和小型开发者负担。

### 3. 集体管理

**优点**：集中授权、降低交易成本。

**难点**：代表性、数据识别、平台垄断、分配透明和跨作品类型覆盖。

### 4. 选择退出

**优点**：以默认可训练降低许可堵塞，同时保留权利人自主。

**难点**：

- 退出是仅影响未来训练，还是要求撤回既有模型影响；
- 权利人如何证明机器可读声明已被读取；
- 大平台是否借标准控制许可入口；
- 退出过多是否使开放模型和小型开发者承担不成比例成本。

### 5. 复合机制

更可行的组合可能是：

- 公共领域、开放许可和明确授权数据自由使用；
- 合法来源、低替代使用适用较宽例外并尊重退出；
- 高价值数据库或高替代商业训练适用集体许可／法定报酬；
- 非法来源、规避措施和高复现输出承担较严责任；
- 对小型、科研和公共利益主体设置差异化负担。

## 七、争议板块五：透明、证据偏在与商业秘密

### 1. 透明的功能

透明不是为了向公众披露全部训练集或模型参数，而是服务于：

- 权利人识别作品是否被使用；
- 法院判断来源和合理使用条件；
- 监管者审查合规；
- 审计者验证退出、删除和复现风险；
- 用户了解内容来源和模型限制。

### 2. 分层透明

| 对象 | 可披露内容 |
|---|---|
| 监管者／法院 | 更完整的来源记录、授权、技术措施处理和审计资料 |
| 独立审计者 | 受保密义务约束的训练集抽样、风险和遗忘验证 |
| 权利人 | 作品匹配结果、权利保留执行、申诉渠道 |
| 公众／用户 | 数据类别、主要来源政策、生成标识和风险说明 |

### 3. 举证责任

由于训练集和模型事实由提供者控制，可以要求其保存并说明：

- 数据来源类别及合法性文件；
- 权利保留和退出处理；
- 训练集版本和删除记录；
- 高复现风险测试；
- 对特定通知采取的措施。

但“无法完整说明”不宜自动等同实体侵权。应结合控制程度、保存义务、故意毁损和对方已提出的初步证据决定不利推定。

## 八、争议板块六：机器遗忘与停止侵害

### 1. 传统停止侵害的困难

删除训练文件不一定消除模型权重中的影响；要求销毁整个模型又可能影响大量合法数据、用户和公共利益。

### 2. 可选择的救济工具

- 删除或隔离训练源文件；
- 从未来训练集中排除；
- 对特定输出进行抑制或过滤；
- 局部微调、反向训练或模型更新；
- 可验证机器遗忘；
- 对无法合理消除的历史影响支付赔偿；
- 由独立审计者验证执行效果。

### 3. 比例性变量

- 侵权来源的恶性；
- 特定作品对模型的影响和复现概率；
- 技术措施的实际效果；
- 执行成本及对第三方的影响；
- 模型是否存在大量合法用途；
- 是否有更温和而同样有效的替代措施。

机器遗忘不是当然救济，也不能因技术困难被永久排除；其适用应建立在可验证性与比例性之上。

## 九、相对共识、真正未决问题与压力测试

### 1. 相对共识

- 训练必须按获取、准备、学习、模型形成和输出分段。
- 非表达性目的不能自动洗白非法获取或稳定存储。
- 来源、商业性、过拟合、市场替代和许可条件都是重要变量。
- 输入端的宽免不等于输出端免责。
- 全面许可与全面豁免都面临实施困难。
- 来源记录、透明和权利保留是权利行使的重要基础。

### 2. 真正未决问题

1. 数字复制权是否应增加传播性或公众接触风险？
2. 三步检验能否在我国创造未列举的训练例外？
3. 训练许可市场是受保护的正常市场，还是由权利扩张形成的循环市场？
4. 机器可读退出应适用于未来训练还是既有模型？
5. 权利人如何证明特定作品进入训练集并影响模型？
6. 机器遗忘由谁验证，达到何种程度才算履行？
7. 如何防止集体许可和退出基础设施被少数平台控制？

### 3. 压力测试

| 新事实 | 首先承压的观点 | 原因 |
|---|---|---|
| 低成本、覆盖广泛的许可基础设施出现 | 以交易成本支持全面合理使用 | 许可不可行前提减弱 |
| 模型可高概率逐字／逐像复现 | 非表达性、低替代路径 | 具体表达吸收和市场替代证据增强 |
| 完全授权或合成数据达到同等性能 | 未授权训练必要性论证 | 必要性和比例依据下降 |
| 流式读取且无任何可还原副本 | 有技术处理即复制 | 固定与法益损害需重新说明 |
| 训练集长期保存并向内部人员提供原作检索 | 训练目的整体豁免 | 数据库已产生独立使用风险 |
| 独立审计可验证来源和遗忘 | 以黑箱反对举证和救济 | 技术不可行性理由减弱 |

## 十、解释论与制度方案：建议采用“六层训练审查”

### 第一层：来源

确认公开状态、授权、技术措施、合同、个人信息与商业秘密问题。

### 第二层：阶段行为

逐项还原抓取、复制、缓存、清洗、训练、保存和输出，不用“训练”概括。

### 第三层：权项构成

判断副本的稳定性、可还原性、表达再现和功能；说明为何进入或不进入复制权。

### 第四层：限制或许可

按目的、数据类型、商业性、权利保留、许可市场和替代效果选择合理使用、TDM、退出或付酬。

### 第五层：证明

配置来源记录、初步证明、说明义务、审计和不利推定，兼顾商业秘密。

### 第六层：救济

在删除、抑制、更新、遗忘、赔偿和未来合规之间选择最小必要而有效的措施。

## 十一、继续研究的板块化选题

1. **复制权构成的技术分段**：流式读取、缓存、向量化和训练库保存。
2. **训练许可市场的规范地位**：正常市场还是循环论证。
3. **机器可读退出标准**：声明格式、识别义务和平台互操作。
4. **来源说明与商业秘密**：法院、审计者、权利人和公众的分层披露。
5. **可验证机器遗忘**：效果标准、审计和比例救济。
6. **小型开发者差异化义务**：避免许可基础设施固化平台优势。
7. **高复现模型的举证规则**：输出证据如何反推训练事实。
8. **数据专条与著作权的竞合**：绕过技术措施获取训练语料时如何选择法源。

## 十二、面试问题模块

### 1. 基础问题

1. 大模型训练是否侵犯复制权？
2. 非作品性使用是否足以排除侵权？
3. 我国第 24 条能否容纳商业训练？
4. 是否应采取法定许可或选择退出？
5. 训练数据透明会不会泄露商业秘密？
6. 退出后是否必须机器遗忘？
7. 如何处理训练集证据偏在？

### 2. 30 秒回答

> 我不会把训练回答成“一律合理使用”或“每件作品逐一许可”。应按来源、阶段行为、复制权构成、限制或许可、证明和救济六层审查。违法获取不能被统计学习目的洗白；合法来源、低复现、低替代并尊重机器可读保留的训练可以有较宽空间；高替代商业训练则可考虑集体许可或法定报酬。侵权成立后还要在删除、输出抑制、模型更新和机器遗忘之间作比例选择。

### 3. 90 秒回答

> 训练数据的争议已经前移到复制权、后移到证据和机器遗忘。首先，抓取、缓存、清洗、训练和长期保存必须分段，不能用最终统计学习目的覆盖前端完整复制。其次，来源合法性具有独立意义，绕过措施、盗版库和泄露数据不能因训练有创新价值而正当化。再次，合理使用应从统一的转换性标签改为条件矩阵，考察科研或商业用途、数据形态、权利保留、许可市场、过拟合和输出替代。制度上，我支持对合法来源、低替代使用提供较宽空间，对高替代商业训练探索退出、集体许可或法定报酬。由于证据偏在，可要求提供者保存来源和退出记录，但不能把无法解释模型自动等同侵权。救济也不应一律销毁模型，而应比较删除、抑制、更新、遗忘和赔偿的效果与成本。

### 4. 3 分钟展开顺序

1. 说明为什么合理使用问题不能先于来源和复制权；
2. 报告传统复制、非作品性使用和功能重构三条路径；
3. 用六维条件矩阵分析合理使用；
4. 比较个别授权、法定许可、集体管理和退出；
5. 讨论分层透明、证据偏在和商业秘密；
6. 以高复现模型和流式无副本两个反例压力测试；
7. 提出六层训练审查。

### 5. 高频追问

**问：训练不向公众传播原作，为什么还可能侵犯复制权？**

> 复制权通常并不以向公众传播为必要。下载、缓存和长期保存可能已经形成稳定副本；非传播目的更适合进入构成解释或合理使用的进一步分析，而不是自动免责。

**问：公开网页是不是默认允许训练？**

> 公开可访问不当然等于授权。还要看技术措施、机器可读保留、合同成立和具体法定限制；但平台单方声明也不能当然创造超出著作权法的禁止权。

**问：选择退出是否最平衡？**

> 它能降低逐项许可成本，但还要解决既有模型、声明识别、标准垄断、孤儿作品和小型开发者负担，因此只是基础设施的一部分。

**问：无法彻底遗忘是否意味着只能赔偿？**

> 不一定。可以组合删除训练库、输出抑制、局部更新、未来排除和赔偿；关键是措施有效、可验证且不过度影响合法数据和第三方。

### 6. 容易失分的表达

- 不说“训练只学习思想，所以不复制”。
- 不说“只要发生技术复制就必须逐项授权”。
- 不用“转换性”一个词结束合理使用分析。
- 不把公开可访问等同于默示许可。
- 不把无法公开完整训练集等同于无需承担说明义务。
- 不把机器遗忘写成已经成熟、可以无成本执行的当然救济。
