# 反不正当竞争法一般条款、商业道德与行为类型化：争议深化版

> [!summary] 核心判断
> 一般条款争议的真正分界，不是“要不要保护新成果”，而是能否从**原告利益值得保护**跨越到**被告采用了可类型化的非效能竞争手段，并造成竞争过程或秩序损害**。随着 2025 年新《反不正当竞争法》增加数据专条，适用顺序更应明确：**先专门知识产权法—再反不正当竞争法具体条款—最后才是一般条款**。

> [!important] 证据边界
> 本页整合 [[研究趋势/争议专题/反不正当竞争法一般条款、商业道德与行为类型化|原争议专题]]、[[研究趋势/面试专题/数据与商业秘密研究路径_面试表达版_2026-07-24|数据与商业秘密增量报告]] 以及模型、智能体、平台竞争和知识产权边界论文。文中的“遮断”“闸门”和“非效能竞争”是跨论文整合工具，须与各作者具体语境区分。

## 一、问题的提出：为什么“有投入＋被复制＋受损”不是完整论证

### 1. 常见但循环的推理

> 原告投入巨大 → 成果有价值 → 被告节省成本 → 原告受损 → 被告搭便车 → 行为不正当。

这条推理缺少两个关键环节：

1. 为什么该利益应当由法律排他保护，而不是通过更高效率竞争被转移？
2. 被告使用了什么不同于正常模仿、学习和替代的非效能手段？

如果仅以投入和损失证明不正当，任何成功竞争都可能被描述为侵权。

### 2. 五个必须分开的判断

1. 原告是否存在合法、具体的竞争利益；
2. 专门法是否已经保护、拒绝保护或将对象留在公共领域；
3. 反不正当竞争法是否已有混淆、商业秘密、网络或数据等具体条款；
4. 被告行为是否可以归入欺骗、强制、混淆、不正当获取、权限滥用、破坏措施等类型；
5. 行为是否造成超出单纯利润转移的竞争秩序损害。

### 3. 三种一般条款风险

- **准知识产权化**：无门槛、无期限、无公示地禁止复制成果。
- **道德直觉化**：以“不劳而获”“不够厚道”替代法定行为分析。
- **结果责任化**：只因原告流量、用户或利润下降就认定违法。

## 二、学术谱系：从补充保护到体系遮断与行为中心

### 阶段一：一般条款作为新型利益的弹性补充

面对成文类型不能预见的新商业模式，早期实践常通过诚实信用、商业道德和一般条款保护：

- 未注册标识；
- 网页和平台成果；
- 数据、流量和用户资源；
- 未达知识产权门槛的创意；
- 新型网络干扰行为。

该路径的优点是适应性强，缺点是保护范围和行为标准不稳定。

### 阶段二：知识产权边界与认知经济性

- [[论文库/知识产权法与反不正当竞争法一般条款的关系——以图式的认知经济性为分析视角_蒋舸|蒋舸]]强调知识产权法图式、一般条款和认知成本，反对无边界补充。
- [[论文库/反不正当竞争法补充保护知识产权的有限性_孔祥俊|孔祥俊]]强调补充保护的有限性。
- [[论文库/侵权法在私法秩序生成中的谦抑性——以竞争秩序的生成为核心_解亘|解亘]]进一步提出专门制度对周边信息利用的遮断效应。

一般条款开始受到作品门槛、权利期限、法定例外和公共领域的体系约束。

### 阶段三：商业道德由经验伦理转向竞争功能

- [[论文库/反不正当竞争法商业道德标准的流变与重构_孔祥俊|孔祥俊]]将商业道德客观化为维护不受扭曲竞争的功能标准。
- [[论文库/“搭便车”的竞争法规制_冯术杰|冯术杰]]指出模仿、借鉴和利用他人成果本是竞争常态，搭便车不能当然违法。
- [[论文库/竞争行为正当性评价中的商业惯例因素_蒋舸|蒋舸]]说明商业惯例是判断线索而非决定性法源。

判断中心从“行为不够公平”转向“竞争是否因非效能手段被扭曲”。

### 阶段四：行为类型化与数字竞争

- [[论文库/商品与销售方式二分视角下不正当竞争行为的类型化_侯利阳|侯利阳]]区分商品成果利用和销售方式干扰，配置不同门槛。
- [[论文库/人工智能模型的竞争利益范畴_贾海东|贾海东]]要求从技术属性、主营市场、行为和因果关系限制模型保护。
- [[论文库/智能体交互的反不正当竞争法规制研究_冯晓青_张云蔚|冯晓青、张云蔚]]指出智能体绕过旧流量入口可能是创新竞争，仅在无授权取数、权限滥用或实质秩序损害时介入。

一般条款进入数据、模型和智能体场景后，行为中心主义进一步加强。

### 阶段五：2025 年新法具体条款的反向限缩

数据专条已经对合法持有、不正当获取使用、权益损害和竞争秩序作出规定。新型数据争议原则上应先适用专条，不能因为一般条款更宽而跳过法定要件。

具体条款越完善，一般条款的功能越应集中于真正未被类型覆盖、又能说明非效能手段和竞争损害的剩余情形。

## 三、争议板块一：专门法未保护是否意味着存在“法律漏洞”

### 1. 有限补充路径

**论证链条**：

1. 知识产权类型无法穷尽市场创新；
2. 新型攫取可能造成显著损害；
3. 若完全拒绝竞争法，会放任规避专门法形式的新行为；
4. 一般条款可只规制行为而不创设对世权。

**典型适用**：盗取未公开模型参数、欺骗获取合作数据、冒用用户权限、破坏平台运行。

### 2. 体系遮断路径

**论证链条**：

1. 专门法不仅规定保护，也有意设置门槛、期限和例外；
2. 不满足独创性、新颖性、秘密性或保护期届满，可能是自由利用的制度选择；
3. 竞争法若提供同等复制禁止，会架空专门法；
4. 一般条款只能处理独立的不正当行为，不能恢复被排除的客体权。

**典型排除**：复制进入公有领域的作品、利用未受保护的思想风格、合法反向工程。

### 3. 如何判断“不保护”是漏洞还是制度选择

| 判断因素 | 更像制度选择 | 更像真正剩余问题 |
|---|---|---|
| 专门法明确设置门槛／期限 | 是 | 否 |
| 行为只是复制保护期届满成果 | 是 | 否 |
| 行为另有欺骗、盗取或权限滥用 | 否 | 是 |
| 保护结果等同完整排他权 | 是 | 否 |
| 救济只针对不正当手段 | 否 | 是 |
| 新行为破坏竞争机制而非只节省成本 | 否 | 是 |

### 4. 综合判断

“专门法不保护”既不意味着竞争法绝对不得介入，也不意味着当然存在漏洞。关键是是否存在**独立于成果复制本身的不正当行为基础**。

## 四、争议板块二：商业道德、行业惯例和诚实信用如何客观化

### 1. 行业惯例的有限作用

行业惯例可以证明：

- 经营者对某种权限或合作边界的共同预期；
- 行为人是否知道某种获取方式异常；
- 技术接口、数据调用或广告投放的通常规则；
- 合理注意和风险分配。

但惯例不能当然决定违法，因为：

- 行业惯例可能由在位者形成并排斥创新；
- 某些惯例本身可能限制竞争；
- 新技术正是通过打破旧惯例提高效率；
- 当事人之间的习惯不能自动对抗第三人。

### 2. 诚实信用不能独立替代构成要件

诚实信用适合解释义务和补充关系，但直接以其判定竞争违法会产生：

- 标准主观化；
- 结果导向；
- 司法可预见性下降；
- 不同法域规则混用。

应将其转化为更具体的行为和损害变量。

### 3. 商业道德的功能化问题

可以追问：

1. 行为是否通过欺骗影响交易相对人选择？
2. 是否以强制、威胁或锁定阻止自由交易？
3. 是否造成来源混淆或虚假关联？
4. 是否违反权限取得非公开资源？
5. 是否破坏技术措施、接口或服务运行？
6. 是否通过自我优待、封锁或滥用平台规则扭曲市场？

“违反商业道德”应是这些具体判断的总结，而不是分析起点。

## 五、争议板块三：“搭便车”何时仍有规范意义

### 1. 搭便车不是当然违法

竞争中的学习、模仿、兼容和替代通常都会利用先行者的信息或市场：

- 通用设计被模仿；
- 公开价格被汇总；
- 消费者评价被引用；
- 公开接口被兼容；
- 进入公有领域的表达被再利用。

如果任何节省成本都违法，市场竞争将退化为永久先占。

### 2. 搭便车可以作为问题线索

它仍可提示：

- 被告是否避免了正常市场进入成本；
- 成本节省来自效率还是欺骗、盗取和权限滥用；
- 是否直接替代原告产品；
- 是否破坏持续投入激励；
- 是否有可行的合法替代路径。

### 3. “效能竞争／非效能竞争”区分

| 效能竞争 | 非效能竞争 |
|---|---|
| 从公开来源独立开发 | 窃取非公开资料 |
| 提高搜索和比较效率 | 欺骗用户或冒充来源 |
| 兼容接口、降低转换成本 | 滥用权限、破坏认证 |
| 提供更低价或更好产品 | 强制、胁迫、恶意干扰 |
| 合法反向工程 | 违反保密义务或盗取样品 |

这一二分不是机械清单。还要看市场结构、消费者影响、技术必要性和比例。

## 六、争议板块四：行为类型化应围绕成果还是竞争过程

### 1. 商品成果与销售方式二分

侯利阳的类型化思路可用于区分：

- **商品／成果利用**：模仿产品、数据、模型能力或内容，介入门槛应较高，避免创造准知识产权。
- **销售方式／竞争过程干扰**：流量劫持、强制跳转、虚假评价、权限滥用和破坏服务，更容易识别独立不正当性。

### 2. 建议采用六类行为原型

1. **混淆型**：冒充来源、虚假关联、关键词导致误认。
2. **欺骗／强制型**：误导用户、胁迫交易、虚假认证。
3. **不正当获取型**：窃取、欺诈、滥用权限、违反保密。
4. **技术破坏型**：绕过或破坏措施、恶意不兼容、干扰运行。
5. **平台规则滥用型**：自我优待、虚假交易、恶意退货、封锁。
6. **市场封锁型**：拒绝必要访问、排除竞争、强化锁定。

新行为如果不能完全归入法定类型，也应说明与这些原型的功能相似性。

### 3. 行为类型化的限度

- 同一行为可能跨多个类型；
- 技术绕过不一定不正当，例如互操作和安全研究；
- 市场损害可能随平台力量和替代渠道变化；
- 类型不能替代因果关系和比例救济。

## 七、争议板块五：模型、知识蒸馏和智能体

### 1. 模型竞争利益

模型可能包含：

- 代码和结构；
- 参数和权重；
- 训练数据关系；
- API 和访问控制；
- 特定能力及市场表现。

不同部分可能适用著作权、商业秘密、专利、合同或竞争法。不能因为“模型有价值”统一确立模型权。

### 2. 知识蒸馏

应区分：

- 合法访问公开 API 后观察输出；
- 违反调用频率、用途或身份限制；
- 盗取参数或内部文件；
- 用大量查询复制特定能力；
- 输出替代是否显著；
- 是否存在更具体的商业秘密或合同基础。

能力相似和市场竞争本身不当然不正当；绕过措施、虚假身份、盗取秘密和实质替代独立开发成本则提高介入理由。

### 3. 智能体绕过平台入口

智能体帮助用户比较、切换和直接交易，可能：

- 降低搜索和转换成本；
- 削弱平台流量和广告模式；
- 提高跨平台竞争；
- 同时带来无授权取数、权限滥用和安全风险。

保护既有流量入口可能维护低效锁定。应把创新性绕过与不正当获取分开。

### 4. 一般条款的适用边界

模型和智能体案件至少应回答：

1. 被保护的是具体参数、数据、接口还是抽象能力？
2. 专门法和合同已保护到何种程度？
3. 获取来源和权限是否正当？
4. 行为是效率创新还是规避独立开发？
5. 是否造成产品替代、系统安全或动态竞争损害？
6. 救济会不会禁止独立开发和兼容竞争？

## 八、争议板块六：数据专条对一般条款的影响

### 1. 适用顺序

数据案件原则上应依次审查：

1. 商业秘密条款；
2. 2025 年《反不正当竞争法》第 13 条第 3 款；
3. 其他互联网具体条款；
4. 确有剩余时才适用第 2 条一般条款。

### 2. 为什么不能跳回一般条款

数据专条已经明确：

- 他人合法持有的数据；
- 不正当获取或使用；
- 合法权益损害；
- 市场竞争秩序扰乱。

若一般条款只要求“投入＋未经同意＋损失”，就会规避更严格的法定要件。

### 3. 仍可能需要一般条款的情形

- 行为不直接获取或使用数据，却以其他方式破坏数据产品交易；
- 主体或技术场景超出专条，但存在可类型化非效能手段；
- 新型平台组织行为尚未被具体条款覆盖；
- 需要处理数据条款之外的混淆、虚假关联或系统性封锁。

即使如此，也须说明为何具体条款不能涵盖。

## 九、竞争损害：从原告损失转向竞争过程

### 1. 原告损失不等于竞争损害

正常竞争会造成：

- 价格下降；
- 客户转移；
- 流量减少；
- 利润下降；
- 商业模式被替代。

这些结果本身可能恰恰说明竞争有效。

### 2. 可识别的竞争损害

- 消费者因欺骗或混淆无法真实选择；
- 竞争者通过窃取而非创新规避进入成本；
- 平台利用控制力封锁市场或自我优待；
- 数据或接口被恶意破坏，市场服务无法运行；
- 违法行为降低持续创新和数据生产激励；
- 用户被锁定，转换和多归属受到不合理限制；
- 市场进入和技术兼容被不当排除。

### 3. 动态竞争

数字市场还应观察：

- 新技术是否打破旧平台入口；
- 短期损害是否换来长期竞争；
- 保护是否固化在位者；
- 接口开放是否带来安全和投资成本；
- 数据控制是否形成不可替代优势。

## 十、相对共识、真正未决问题与压力测试

### 1. 相对共识

- 原告利益值得保护不等于被告行为不正当。
- 投入、获益和搭便车不能单独完成违法证明。
- 专门法的门槛、期限和例外具有体系约束。
- 有具体条款时应优先适用具体条款。
- 商业道德和行业惯例应转化为客观行为与竞争功能。
- 一般条款救济必须保持行为针对性。
- 新型模型和智能体案件应关注权限、行为和竞争损害，而非抽象成果权。

### 2. 真正未决问题

1. 专门法的“不保护”何时具有遮断效应？
2. 非效能竞争是否能形成稳定、可司法操作的标准？
3. 行业惯例由平台单方制定时有多大证明力？
4. 数据专条与一般条款的剩余空间多大？
5. 智能体绕过流量入口何时构成创新而非破坏？
6. 知识蒸馏的能力替代是否足以构成竞争损害？
7. 如何证明动态竞争损害而不依赖抽象预测？

### 3. 压力测试

| 新事实 | 首先承压的观点 | 原因 |
|---|---|---|
| 被告从公开信息独立开发更优替代品 | 搭便车／投入保护 | 行为属于效率竞争 |
| 被告盗取密钥复制实时产品 | 绝对自由利用 | 存在独立不正当获取 |
| 智能体显著降低用户转换成本 | 保护平台流量入口 | 可能固化低效锁定 |
| 智能体冒用用户权限批量取数 | 一概创新竞争 | 权限滥用基础明显 |
| 专门法保护期已经届满 | 一般条款成果保护 | 会恢复被终止排他 |
| 新法已有严格数据要件 | 一般条款宽松兜底 | 规避法定类型 |

## 十一、解释论方案：建议采用“适用顺序＋四道闸门”

### 适用顺序

1. 专门知识产权法；
2. 反不正当竞争法具体条款；
3. 一般条款。

### 四道闸门

#### 第一闸：体系边界

是否冲撞专门法的门槛、期限、例外和公共领域？

#### 第二闸：行为类型

能否识别混淆、欺骗、强制、不正当获取、权限滥用、技术破坏或市场封锁？

#### 第三闸：竞争损害

是否损害消费者选择、创新过程、市场进入、系统运行或动态竞争，而不只是原告利润？

#### 第四闸：比例救济

是否只禁止具体不正当行为，为独立开发、合法来源、兼容和替代竞争保留空间？

## 十三、面试问题模块

### 1. 基础问题

1. 知识产权法不保护的成果能否用一般条款保护？
2. “搭便车”为什么不能直接证明不正当竞争？
3. 商业道德应如何客观化？
4. 一般条款与数据专条如何分工？
5. 模型能力被蒸馏是否构成不正当竞争？
6. 智能体绕过平台流量入口是否违法？
7. 如何证明竞争秩序损害？

### 2. 30 秒回答

> 一般条款不能因为原告有投入、被告获益就自动兜底。我的适用顺序是先专门知识产权法，再反不正当竞争法具体条款，最后才是一般条款。一般条款应经过体系边界、行为类型、竞争损害和比例救济四道闸门，识别欺骗、混淆、不正当获取、权限滥用等非效能手段，并避免把救济变成无期限准知识产权。

### 3. 90 秒回答

> 一般条款的难点是法律适应性与公共领域稳定之间的平衡。有限补充论正确指出，新业态可能存在成文法未覆盖的恶劣行为；蒋舸、孔祥俊、冯术杰和解亘等路径则提醒，不能从成果有价值、原告有投入和被告获益直接推出违法。尤其新法已有数据专条后，数据案件必须先完成合法持有、不正当获取使用、权益损害和竞争秩序的要件审查。我的方案是适用顺序加四道闸门：先看是否冲撞专门法的门槛和公共领域，再识别欺骗、权限滥用等行为类型，证明超出利润转移的竞争损害，最后把救济限制在具体行为。模型蒸馏和智能体绕过也应按这个结构判断，而不是先承认抽象模型权或流量权。

### 4. 3 分钟展开顺序

1. 揭示“投入—受损—搭便车”循环；
2. 比较有限补充与体系遮断；
3. 解释商业道德和惯例的功能化；
4. 说明搭便车只是线索；
5. 建立六类行为原型；
6. 用模型、蒸馏和智能体检验；
7. 说明数据专条的优先适用；
8. 提出四道闸门。

### 5. 高频追问

**问：是不是只要知识产权法不保护，一般条款就绝对不能介入？**

> 不是。若存在独立的欺骗、窃取、权限滥用或技术破坏，一般条款仍可处理；但不能只因成果未受保护就恢复相同的复制禁止权。

**问：搭便车完全没有法律意义吗？**

> 它可以提示成本节省和利益转移，但还要继续查明成本节省来自效率创新还是不正当手段，并证明竞争过程损害。

**问：行业普遍认为不道德，法院还不能直接采纳吗？**

> 行业惯例是证据，但可能由在位者形成或排斥创新。法院应说明该惯例保护了什么竞争机制，并检验其是否与法律和公共利益一致。

**问：智能体绕过平台入口导致平台流量下降，是否构成损害？**

> 流量下降本身可能是竞争结果。要看智能体是否通过合法授权降低用户搜索成本，还是冒用权限、无授权取数或破坏系统。

### 6. 容易失分的表达

- 不说“反不正当竞争法就是知识产权兜底法”。
- 不说“有投入就有竞争权益”。
- 不说“搭便车违反商业道德，所以违法”。
- 不把原告损失直接等同竞争秩序损害。
- 不跳过数据专条直接适用一般条款。
- 不把模型能力、平台流量或商业模式当然客体化。
