# AIGC 可版权性、创作行为与替代保护：争议深化版

> [!summary] 核心判断
> AIGC 争议已经由早期的“AI 能不能成为作者、生成结果是不是作品”，推进为四个相互连接但不能混同的判断：**自然人是否实施创作行为—哪些表达可归属于自然人—保护范围如何随贡献收窄—不构成作品时是否需要替代保护**。当前真正没有解决的，不是抽象的“工具还是主体”，而是概率生成环境中的规范归因与证据阈值。

> [!important] 证据边界

## 一、问题的提出：为什么“结果像作品”已经不足以回答争议

### 1. 四个经常被混用的命题

| 命题 | 实际问题 | 不能由什么直接推出 |
|---|---|---|
| 结果具有独创表达外观 | 客体看起来是否具有可感知差异 | 不能直接推出特定自然人是作者 |
| 用户实施了创作行为 | 用户是否直接或可归责地形成表达 | 不能由投入时间、提示数量或满意结果直接推出 |
| 用户是作者 | 具体表达能否规范归属于该用户 | 不能由合同、平台规则或模型所有权倒推 |
| 生成内容应受某种保护 | 是否存在激励或攫取问题 | 不能反向证明它属于著作权作品 |

### 2. 三类典型事实必须分开

1. **纯指令生成**：用户提出主题、风格或功能需求，模型决定主要表达细节。
2. **深度交互生成**：用户持续调整参数、局部重绘、锁定元素、筛选并编排多个输出。
3. **AI 辅助创作**：人先形成或直接修改可识别表达，模型承担润色、扩展、转换或技术执行。

争议的难点主要集中在第二类。第一类较难证明用户形成全部表达，第三类通常可以保护人的既有贡献；第二类要求建立可重复适用的归因标准。

### 3. 研究问题已经发生的三次迁移

- **第一次迁移：主体问题转向人的贡献。** 是否承认 AI 主体，不再是解决生成内容保护的必要前提。
- **第二次迁移：工具标签转向过程事实。** “AI 是工具”只是描述，不能证明用户控制了哪些具体表达。
- **第三次迁移：作品资格转向证据和权利强度。** 即使准入，也要回答保护哪些部分、如何举证、赔偿多大以及第三人如何识别边界。

## 二、学术谱系：从主体说、工具说到贡献—控制—证据

### 阶段一：2017—2020 年——作品、作者与归属被合并讨论

早期研究通常在同一问题中处理：

- AI 生成结果是否具备客观独创性；
- AI 能否成为作者；
- 权利应归开发者、用户、投资者还是模型所有者；
- 若不承认作品，投资是否完全失去保护。

肯定路径多使用工具类比、客观独创性、投资激励或拟制作者；否定路径则强调自然人作者、自由意志和作品的人格基础。此阶段的缺陷是：作者归属规则经常被用来倒推作品成立，作品外观又被用来倒推人的创作。

### 阶段二：2021—2023 年——工具说受到概率生成冲击

- [[论文库/论人工智能生成内容的可版权性_以用户的独创性表达为视角_蒋舸|蒋舸]]把问题转向用户是否作出最低限度独创性表达。
- [[论文库/人工智能生成物中用户的独创性贡献_崔国斌|崔国斌]]开始区分提示、选择、修改与最终表达之间的贡献。
- [[论文库/ChatGPT生成的内容受著作权法保护吗？_王迁|王迁]]强调自然人须直接决定表达要素，反对由结果倒推创作。
- [[论文库/重思“表达”概念的规范意义——兼论人工智能用户指令行为的法律性质_李琛|李琛]]从作品语言的直接运用界定表达行为，指出一般指令多为需求而非表达。

“工具说”由结论性标签退居事实起点，贡献说、控制说和表达行为说成为中心。

### 阶段三：2024—2025 年——贡献被拆成可证明的过程

新增研究进一步提出：

- [[论文库/通用人工智能视野下著作权法的逻辑回归从工具论到贡献论|丁文杰]]：用实质表达贡献替代工具标签。
- [[论文库/人工智能生成内容可版权性的认定方法研究_张宪|张宪]]：将人的创作决策与模型决策作概念性分离。
- [[论文库/论著作权法上的创作行为——以人工智能生成内容可版权性争议为切入点_涂藤|涂藤]]：以概括性自然意思和最小表达单元的选择、安排重构创作行为。
- [[论文库/人工智能生成内容的著作权规制研究|杨利华、王诗童]]：以“场景设计—场景固定”和双向训导识别深度用户贡献。
- [[论文库/论用户主张AIGC版权的“最低限度创造性标准”_蒋舸|蒋舸]]：强调不能为 AIGC 另设更高独创性标准，但须确定用户贡献。

讨论由抽象立场转向提示具体性、可复现性、参数、种子、版本记录、选择编排、局部修改和后期编辑。

### 阶段四：2025—2026 年——替代保护与权利强度独立成层

- [[论文库/纯指令类人工智能生成内容的竞争法保护_胡开忠_江璐迪|胡开忠、江璐迪]]：否定纯指令生成物的作品资格，但对具体不当攫取提供竞争法保护。
- [[论文库/人工智能生成内容“作品”属性的名实之辨_刘文杰|刘文杰]]、[[论文库/人工智能生成内容的阶梯式保护体系_孙靖洲|孙靖洲]]：分别提出邻接权或阶梯式弱权利。
- [[论文库/“邻接权兜底保护”路径之反思——从古籍点校到人工智能生成内容_蒋舸|蒋舸]]：反对“先排除作品、再新设权利”的双重识别成本。

争论不再只是作品／非作品，而是公共领域、窄版权、邻接权、特殊权利、合同和竞争法之间的制度选择。

## 三、争议板块一：作品资格应看结果，还是先确认人的创作行为

### 1. 结果／客观独创性路径

**论证链条**：

1. 作品是可与作者身份相对分离的客体；
2. 输出具备可感知差异和最低创造性即可进入保护；
3. 作者和财产权可通过拟制、合同或控制事实另行配置；
4. 过程审查会增加举证和交易成本。

**优势**：司法判断较简洁，避免因技术黑箱排除具有表达价值的新客体。

**根本难点**：若同一提示产生完全不同结果，单看结果无法说明为何权利归属于某一用户；通过合同配置财产权，也不能倒推该用户实施了创作。

### 2. 人类表达／严格控制路径

**论证链条**：

1. 著作权保护人类创作形成的表达；
2. 提示通常描述思想、风格、功能或期待；
3. 模型决定不可预见的具体表达细节；
4. 结果再复杂，也不能替代自然人的创作事实。

**优势**：维护作者概念、思想表达二分和公共领域。

**根本难点**：若用户通过参数锁定、局部重绘和连续编辑稳定决定构图细节，单纯以“模型具有随机性”否定创作，会低估真实的人机协作。

### 3. 最低门槛／认知经济性路径

该路径不是简单的结果说。其核心是：普通作品本就采取低独创性门槛，不应要求 AIGC 用户证明高于传统作者的创造；复杂问题可通过窄保护范围、实质性相似和赔偿控制。

**必须补足的前提**：低门槛只能降低“贡献达到多高”的要求，不能取消“贡献来自自然人”的证明。否则“宽进宽出”会变成“无贡献也进入”。

### 4. 综合判断

作品资格需要同时具备：

- 输出中存在可保护表达；
- 自然人实施了能够形成或选择、安排该表达的行为；
- 行为与具体表达之间具有规范上足够直接的对应；
- 主张权利者能够指出其贡献而不是只描述投入或意图。

## 四、争议板块二：提示、迭代、选择和修改何时成为表达贡献

### 1. 提示词应分成两个不同问题

- **提示词文本自身是否构成作品**：取决于其文字表达是否达到普通作品门槛。
- **提示词是否使用户成为输出作者**：取决于提示与输出具体表达之间的形成关系。

前者成立不当然证明后者。详细提示可能仍停留于主题、风格或功能；简短指令在特定工具中也可能稳定调用用户预先设计的表达结构。

### 2. 六类行为的规范意义

| 用户行为 | 可能贡献 | 不能自动证明 |
|---|---|---|
| 抽象主题／风格指令 | 构思、思想或创作目标 | 对具体表达的形成 |
| 具体构图和关系描述 | 对结构、顺序、位置的设计 | 模型生成的全部细节 |
| 参数、种子和约束锁定 | 可复现性和控制程度 | 参数本身具有独创性 |
| 多轮迭代 | 持续选择和排除 | 反复点击本身就是创作 |
| 从多个输出中选择、编排 | 汇编式选择安排 | 对每个单项输出享有版权 |
| 局部重绘、文字改写和后期编辑 | 直接形成被修改部分 | 未被修改部分也归属于用户 |

### 3. “事前控制”与“事后选择”的边界

严格控制路径担心事后认可随机结果被包装成创作；条件性贡献路径则指出，传统摄影、汇编和剪辑也可能通过选择完成表达。

更稳妥的区分是：

- 单纯从偶然结果中挑选“最喜欢的一张”，通常不足以取得单项全部表达；
- 按预先形成的选择标准，从大量输出中选择、排列、组合成整体，可能形成汇编或编辑贡献；
- 对选中结果进行实质修改，可以就修改部分取得保护；
- 事后选择是否成为创作，应审查选择标准是否具有表达性，而不是只看筛选次数。

## 五、争议板块三：贡献说、控制说与创作行为说是什么关系

| 理论 | 回答的问题 | 不足 |
|---|---|---|
| 工具说 | AI 与人的事实关系 | 不能推出人决定了哪些表达 |
| 控制说 | 输出为何可以归因于人 | “控制”若不具体化，可能只是抽象愿望 |
| 贡献说 | 人贡献了哪些受保护表达 | 概率模型中的贡献难以量化 |
| 创作行为说 | 哪个动作完成表达 | 连续交互过程不易切分 |
| 概念性分离 | 人的决策与模型决策如何区分 | 分离成本高，可能需要日志 |
| 认知经济性 | 在哪个规则节点控制成本 | 不能替代实体贡献判断 |

这些理论不是彼此排斥的完整答案。较完整的组合是：

1. 用创作行为说识别用户做了什么；
2. 用贡献说判断行为形成了哪些表达；
3. 用控制说说明为何可以规范归因；
4. 用概念性分离确定保护范围；
5. 用认知经济性选择举证、侵权和赔偿的调节节点。

## 六、争议板块四：不构成作品后的替代保护

### 1. 公有领域路径

非作品内容原则上自由使用，避免海量、低成本生成内容形成权利拥堵。合同可以约束特定当事人，技术措施可以保护访问，但不产生一般对世排他。

### 2. 竞争法路径

竞争法可以处理：

- 违反权限或技术限制取得内容；
- 大规模、系统性搬运并直接替代特定产品；
- 冒充来源、造成混淆或破坏服务运行；
- 违反合作关系中的保密或诚信义务。

但不能只因“被告没有投入”或“原告内容有市场价值”就产生事实上的复制禁止权。

### 3. 邻接权／特殊权利路径

主张者通常提出短期限、弱权能、标识义务和广泛例外，以保护生成投入。

其成立至少需要证明：

1. 存在合同、技术措施和行为法不能解决的市场失灵；
2. 生成边际成本并非已低到无需排他激励；
3. 权利客体和主体可以被第三人低成本识别；
4. 新权利不会与著作权、数据权和平台规则重复；
5. 期限、例外和许可机制能够控制公共领域成本。

### 4. 综合结论

在上述实证基础尚不充分时，宜保持“作品按人的贡献保护、非作品原则自由、具体不正当行为另行规制”的分层结构。

## 七、相对共识、真正未决问题与压力测试

### 1. 相对共识

- AI 主体资格不是处理 AIGC 的必要前提。
- 简单提示、单次点击、市场价值和投入不能单独证明作者身份。
- 提示词自身的作品性与输出作品的作者认定必须分开。
- 作者资格与财产权配置必须分开。
- 即使承认作品，保护范围也应与人的贡献相匹配。
- 生成日志和标识主要承担证据及透明功能。

### 2. 真正未决问题

1. 人对概率输出施加何种程度的控制，才达到规范归因阈值？
2. 连续交互应以提示轮次、表达单元还是最终编辑行为切分？
3. 无法分离的人机混合表达是整体不保护，还是只提高侵权门槛？
4. 由谁保存日志，日志不完整应承担何种证据后果？
5. 第三人如何识别受保护部分，是否需要权利声明或贡献标示？
6. 非作品生成内容的市场失灵是否足以支持新权利？

### 3. 压力测试

| 新事实 | 首先承压的观点 | 原因 |
|---|---|---|
| 同一提示、参数和种子能够稳定复现关键表达 | 以随机性一概否定创作 | 随机性不再足以区分 AI 与传统工具 |
| 用户只有一句提示，但按预设规则选择并编排一百项输出 | 只看提示长短的路径 | 选择和编排可能独立形成整体表达 |
| 用户写数百条提示，但关键形象始终由模型随机改变 | 以投入和轮次支持创作 | 劳动量不能替代对具体表达的贡献 |
| 生成边际成本趋近于零 | 投资型邻接权 | 激励和市场失灵基础减弱 |
| 强制保存可验证生成日志 | 认为过程永远无法查明的路径 | 证据不可得理由减弱，但隐私和成本问题上升 |

## 八、解释论与制度方案：建议采用“五步贡献测试”

### 第一步：识别主张保护的具体表达

不能只提交完整输出，应指出构图、文字、顺序、选择安排、局部修改等受保护内容。

### 第二步：还原自然人的具体行为

区分主题构思、提示、参数、选择、编排、修改和后期编辑，不以“使用 AI”或“投入很多”概括。

### 第三步：判断行为—表达对应

审查表达指令的具体性、结果稳定性、可复现性、版本变化和修改痕迹，确认人的行为形成了哪些表达。

### 第四步：概念性分离并确定保护范围

对可分离的人类贡献给予保护；模型独立决定部分不因与人的贡献处于同一文件而当然私有化。

### 第五步：配置证明与救济

- 权利主张者原则上承担贡献说明义务；
- 平台掌握日志时，可按证据偏在要求提供必要记录；
- 贡献较弱或混同时，采用较窄范围、较高相似门槛和有限赔偿；
- 不构成作品时，仅对合同违约或具体不正当行为提供相应救济。

## 九、继续研究的板块化选题

1. **生成日志与举证责任**：日志缺失、平台控制和不利推定的边界。
2. **最小表达单元**：如何在图像、音乐、文字和视频中识别人类贡献。
3. **选择编排型创作**：大量随机输出中的汇编贡献与单项权利。
4. **贡献标示制度**：第三人如何识别人类贡献和保护范围。
5. **AIGC 特殊权利的实证前提**：生成成本、市场替代和许可成本。
6. **提示词双重评价**：提示词自身作品性与输出归因的分离规则。
7. **人机混合表达的侵权比对**：只比较可归属于人的部分，还是整体观察。

## 十、面试问题模块

### 1. 基础问题

1. AIGC 是否构成作品？
2. 提示词越详细，用户就越可能成为作者吗？
3. 多轮选择和重生成是否属于创作？
4. “工具说”为什么已经不足？
5. 生成日志在作品认定中有什么作用？
6. 不构成作品的 AIGC 是否应设邻接权？

### 2. 30 秒回答

> 我认为 AIGC 的核心不是结果像不像作品，而是自然人对哪些具体表达作出了可证明的贡献。提示、参数、选择、编排和修改都可能有意义，但提示数量和投入时间不能代替表达归因。我的立场是先识别人类创作行为，再按贡献确定保护范围；日志主要解决证据问题。不构成作品的内容原则上保持自由，只有合同违约或具体不正当攫取才另行规制。

### 3. 90 秒回答

> 我会把结果独创性、人的创作行为、作者身份、保护范围和替代保护分开。严格人类表达路径正确指出，结果复杂不能反推用户创作；贡献和控制路径则提醒，深度交互、参数锁定、选择编排和后期修改可能形成真实表达。两者可以通过“五步贡献测试”协调：先指出受保护表达，再还原用户行为，判断行为与表达的对应，分离模型决策，最后按贡献配置证据和救济。最高法要求综合考虑指令、选定和修改过程，也说明司法重心是贡献审查，而不是凡生成即保护。对于无法证明人类贡献的内容，我原则上不主张自动新设权利，因为仍需证明市场失灵、权利识别和公共领域成本。

### 4. 3 分钟展开顺序

1. 先说明四个命题不能混同；
2. 报告结果说、严格表达说、贡献说和认知经济性路径；
3. 解释提示、参数、选择、编排、修改的不同意义；
4. 提出五步贡献测试；
5. 讨论日志、保护范围和替代保护；
6. 用一个随机输出与一个可复现深度编辑的反例作压力测试。

### 5. 高频追问

**问：为什么不能直接采取最低独创性标准？**

> 可以保持普通作品的最低创造性标准，但还要先证明最低贡献来自自然人。门槛低不等于没有主体归因门槛。

**问：结果由用户选择，为什么选择还不够？**

> 选择可能形成贡献，但要区分对单项随机结果的简单认可与按表达性标准进行的选择、编排。后者更可能形成汇编或编辑贡献。

**问：平台条款写明版权归用户，能否解决？**

> 平台条款可以在合同关系中配置可转让财产利益，但不能创造作品资格，也不能倒推用户实施了创作。

**问：不设新权利会不会打击产业？**

> 需要先证明存在无法由合同、技术措施和竞争法解决的市场失灵。生成成本、市场结构和许可成本没有充分证据时，不宜只以产业价值创设对世权。

### 6. 容易失分的表达

- 不说“AI 是工具，所以用户是作者”。
- 不说“结果有独创性，所以用户有版权”。
- 不把提示词自身作品性与输出归属混为一谈。
- 不把多轮操作数量等同表达贡献。
- 不把最高法“综合考量”表述成已经确认 AIGC 普遍可版权。
