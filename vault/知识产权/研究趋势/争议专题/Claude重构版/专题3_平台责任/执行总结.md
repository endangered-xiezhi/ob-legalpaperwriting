## 三、核心发现

### 3.1 五大争议焦点

1. **避风港规则是否应当重构**
   - 学术主流：维持框架，精细调整
   
2. **算法推荐是否改变注意义务**
   - 技术中立派：否定（崔国斌、王迁）
   - 实质判断派：肯定（部分司法判决）
   
3. **是否应引入强制过滤义务**
   - 欧盟：已引入（第17条）
   - 美国：明确拒绝
   - 中国：学术主流反对
   
4. **"必要措施"的边界**
   - 从单纯删除到关键词屏蔽、视频指纹
   - 须与服务类型和技术能力匹配
   
5. **新型服务的责任认定**
   - 合并存储、解析播放：直接侵权 vs 间接侵权

### 3.2 核心共识

1. 避风港框架仍有价值
2. 强制普遍过滤不可取
3. 平台责任应与能力匹配
4. 需要区分直接/间接侵权
5. "应知"对象是具体侵权事实

### 3.3 三大学术阵营

1. **技术中立派**（崔国斌、王迁）：坚守避风港，反对强制过滤
2. **精细调整派**（孔祥俊、万勇、刘维）：开放框架，类型化调整
3. **实质判断派**（蒋舸、刘鑫）：穿透标签，按控制能力判断
