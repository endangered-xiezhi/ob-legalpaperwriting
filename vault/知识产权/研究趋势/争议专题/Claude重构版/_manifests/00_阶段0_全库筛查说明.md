# 阶段 0：盘点与范围确认

## 任务目标

对 492 份规范论文笔记进行全库筛查，为六个专题分别建立候选论文清单。

## 处理原则

1. **只读元数据层**：题名、作者、年份、trend_topics、research_area、original_keywords、primary_domain、cross_domains
2. **不进行全文阅读**：此阶段只做相关性判断
3. **分批处理**：每批约 200-300 份规范笔记
4. **去重规则**：按"正式题名＋作者"去重

## 六个专题

1. AIGC 可版权性、创作行为与替代保护
2. 大模型训练数据的复制权、合理使用与许可
3. 平台过滤义务、避风港与通知移除

5. 反不正当竞争法一般条款、商业道德与行为类型化

## 分类标准

- **核心直接文献**：题名、关键词或标签直接命中争议主题

- **交叉文献**：涉及相关问题但非主要讨论对象
- **排除文献**：仅关键词命中但实际无关
