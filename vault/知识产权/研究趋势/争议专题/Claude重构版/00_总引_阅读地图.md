# Claude重构版总引：阅读地图

这批文件不是一组平行笔记，而是一个已经多轮加工过的专题包。最适合的读法不是从 `_reading_logs` 或 `_manifests` 开始，而是先读最终综合，再按专题下钻，最后只在需要核对学者、论文、案例或论证来源时回到过程材料。

## 一、文件分层

### A类：最终综合内容，优先阅读

这些文件承担“总答案”和“综合框架”的功能，是最后整合成果所在。

- [[跨专题整合/面试策略总纲|面试策略总纲]]：最适合考前和面试前读，直接给出 7 个专题的立场、追问和话术。
- [[跨专题整合/统一应试知识体系|统一应试知识体系]]：最适合日常复习，负责概念、框架、金句和跨专题组合。
- [[跨专题整合/跨专题理论图谱|跨专题理论图谱]]：最适合理解学术谱系，尤其是蒋舸、崔国斌、王迁、孔祥俊等人的跨专题位置。
- [[六个强制专题_统一整合报告|六个强制专题统一整合报告]]：早期总汇，适合快速知道整批工作的生成逻辑；其中“完成度”状态可能早于后续补充文件，不应作为当前唯一依据。

### B类：专题实质内容，主线阅读

这些文件是每个专题真正应读的正文，包括最终综述、争议重构、候选观点、面试问答。

- 最终综述：一个专题的书面版结论，优先级最高。
- 统一衔接报告：适合把同一专题的不同阶段打通。
- 争议重构：适合理解“为什么会有这些争议”。
- 应试观点/候选观点/问答库：适合转换成面试表达。
- 外部资料：属于资料型正文，不必通读，但要在需要案例、比较法、政策材料时查。

### C类：资料底稿，按需查证

这些文件不适合作为第一遍阅读对象，但很有价值。

- `_reading_logs`：论文阅读卡、批次交接报告、精读日志。用途是核对某个学者到底怎么说、某篇论文怎么用。
- `_external_sources`：外部法条、案例、政策、比较法资料。用途是给最终观点补权威材料。
- `_manifests`：专题筛查清单、论文清单、阶段计划。用途是看材料范围和选文依据。

### D类：过程性/管理性文件，通常不读

这些文件主要记录任务如何完成，不是知识本身的最终载体。

## 二、总阅读顺序

第一遍只建立全局地图：

1. [[跨专题整合/面试策略总纲|面试策略总纲]]
2. [[跨专题整合/统一应试知识体系|统一应试知识体系]]
3. [[跨专题整合/跨专题理论图谱|跨专题理论图谱]]
4. [[六个强制专题_统一整合报告|六个强制专题统一整合报告]]

第二遍进入各专题：

1. 先读该专题的“最终综述”。
2. 再读“应试观点/候选观点/问答库”，把书面结论压缩成口头表达。
3. 对某个争点不稳时，回读“争议重构”。
4. 需要案例、法条、域外材料时，读“外部资料”。
5. 需要准确引用学者或论文时，查 `_reading_logs` 中的阅读卡。

第三遍回到综合：

1. 用 [[跨专题整合/统一应试知识体系|统一应试知识体系]] 复盘概念。
2. 用 [[跨专题整合/面试策略总纲|面试策略总纲]] 练 30 秒、90 秒、3 分钟回答。
3. 用 [[跨专题整合/跨专题理论图谱|跨专题理论图谱]] 练“跨专题串联”，尤其是认知经济性、替代成本、技术中立、利益平衡、类型化。

## 四、最后综合内容在哪里

最后的综合内容主要不在根目录的 [[六个强制专题_统一整合报告|六个强制专题统一整合报告]]，而在 `跨专题整合` 文件夹中：

- 想快速形成面试答案：读 [[跨专题整合/面试策略总纲|面试策略总纲]]。
- 想建立可迁移的知识框架：读 [[跨专题整合/统一应试知识体系|统一应试知识体系]]。
- 想把学者、理论和专题串起来：读 [[跨专题整合/跨专题理论图谱|跨专题理论图谱]]。
- 想知道整合是怎么完成的：读 [[跨专题整合/执行总结|跨专题整合执行总结]] 和 [[跨专题整合/README|README]]，但这两个不是首读正文。

1. 用 [[跨专题整合/面试策略总纲|面试策略总纲]] 建立七专题的短答案。
2. 用每个专题的“最终综述”补足论证细节。
3. 用 [[跨专题整合/统一应试知识体系|统一应试知识体系]] 把概念、框架、金句统一。
4. 用 [[跨专题整合/跨专题理论图谱|跨专题理论图谱]] 做最后一轮升维，把单专题答案变成跨专题回答。

## 六、不要从哪里开始

不要第一遍就从这些地方开始：

- `_reading_logs`：太细，容易陷入论文细节。
- `_manifests`：是材料筛选和任务清单，不是最终知识。
- 各类执行总结、进度报告、交接报告：能说明生成过程，但不适合建立知识体系。
- 外部资料：适合补证据，不适合直接形成观点。

第一遍阅读的核心标准是：先形成“我能说什么”，再补“我为什么这样说”。
