# 专题5 阶段3：外部资料清单

## 法律条文

### 《反不正当竞争法》核心条款

#### 第2条（一般条款）

**2017年修订版**：
```
第二条 经营者在生产经营活动中，应当遵循自愿、平等、公平、诚信的原则，遵守法律和商业道德。

本法所称的不正当竞争行为，是指经营者在生产经营活动中，违反本法规定，扰乱市场竞争秩序，损害其他经营者或者消费者的合法权益的行为。

国家鼓励、支持和保护一切组织和个人依法从事市场经济活动，保护市场竞争秩序和消费者合法权益，保障社会主义市场经济健康发展。
```

**关键术语**：
- 商业道德
- 扰乱市场竞争秩序
- 损害其他经营者或消费者合法权益

#### 第12条（互联网专条）

**2017年修订版**：
```
第十二条 经营者利用网络从事生产经营活动，应当遵守本法的各项规定。

经营者不得利用技术手段，通过影响用户选择或者其他方式，实施下列妨碍、破坏其他经营者合法提供的网络产品或者服务正常运行的行为：
（一）未经其他经营者同意，在其合法提供的网络产品或者服务中，插入链接、强制进行目标跳转；
（二）误导、欺骗、强迫用户修改、关闭、卸载其他经营者合法提供的网络产品或者服务；
（三）恶意对其他经营者合法提供的网络产品或者服务实施不兼容；
（四）其他妨碍、破坏其他经营者合法提供的网络产品或者服务正常运行的行为。
```

#### 1. 海带配额案（最高院指导案例）

**案号**：待查
**裁判要点**：

- 经营者、消费者、竞争秩序三重保护

**引用文献**：
- 孔祥俊、吴伟光等多篇论文引用

#### 2. 大众搬家案

**争议焦点**：
- 商号混淆
- 商业道德判断

#### 3. 大众点评诉百度案

**争议焦点**：
- 数据抓取
- 搭便车
- 商业道德的浅层道德谴责批判

**孔祥俊批评**：停留在"不劳而获"的道德评价，未充分展开市场竞争功能分析

### 互联网专条案例

#### 4. 百度诉奇虎案（某度诉某虎案）

**裁判要点**：
- 创设"非公益必要不干扰原则"
- 流量劫持认定

**学术批评**：
- 冯术杰：扭曲竞争自由底色，倒置了"法无明文禁止即自由"逻辑
- 侯利阳：应区分商品类与销售方式类

#### 5. 腾讯诉世界星辉屏蔽广告案

**争议焦点**：
- 视频广告屏蔽
- 商业惯例的不当适用

**蒋舸批判**：法院以"屏蔽广告已成为行业普遍做法"认定合法，是用商业惯例代替正当性判断的危险倾向

#### 6. 爱奇艺诉某狗案

**裁判思路**：
- 宽认竞争关系，严认主营市场

#### 7. 网络恶意不兼容案例

**待补充**：孔祥俊《网络恶意不兼容的法律构造与规制逻辑》中的案例

### 模型/智能体案例

#### 8. 抖音诉亿睿科"变身漫画特效"模型案

**争议焦点**：
- 模型结构与参数不受著作权保护，能否构成竞争利益
- 投入成本是否等同于竞争利益

**学术分析**：
- 贾海东：批判"权益-损害"范式；应用主营市场界分，抖音与B612主营市场不同
- 周辉、北京知识产权法院：多篇论文分析

#### 9. 微博诉脉脉案

**裁判要点**：
- 用户授权不能当然替代平台授权

**智能体语境应用**：
- 冯晓青引用，说明智能体交互需平台授权

#### 10. 点点蚁案

**裁判要点**：
- 自动点击违反平台规则
- 增加风控成本构成不正当竞争

**智能体语境应用**：
- GUI模式+无障碍权限的风险

#### 11. 亚马逊诉Perplexity AI案（国外）

**争议焦点**：
- 智能体跨平台调用
- 用户授权、技术中立与平台数据流量利益冲突

#### 12. AI写作案（国内）

**裁判要点**：
- 违反平台规则
- 攫取成果认定不正当竞争

## 国际条约与比较法

### 《保护工业产权巴黎公约》

**第10条之二**（不正当竞争定义）：
```
凡在工商业事务中违反诚实惯例的竞争行为构成不正当竞争行为。
```

**三大经典类型**：
1. 混淆（confusion）
2. 商业诋毁（disparagement）
3. 误导（misleading）

**冯术杰强调**：这三大类型至今仍对各国立法和实践具有重要指导意义

### 《欧盟不正当商业行为指令》

**核心标准**：消费者权益保护

**冯术杰借鉴**：将消费者保护列为反不正当竞争法的价值目标和不正当竞争行为的认定标准

### 欧盟判例

#### 凯科和密斯豪德案（Keck and Mithouard）

**确立**：商品与销售方式二分

**侯利阳引用**：
- 商品类行为：保护商品或服务本身
- 销售方式类行为：限制某种促销或盈利路径

#### 家庭出版社案

**裁判要点**：
- 销售安排若已成为商品内容，应按商品处理

### 法国竞争法

**寄生行为（parasitisme）理论**：

**冯术杰借鉴**：
- 个性化成果和知名度是两类权益依据
- 损害表现为竞争优势侵害及交易机会侵占
- 搭便车可发生于竞争者或非竞争者之间
