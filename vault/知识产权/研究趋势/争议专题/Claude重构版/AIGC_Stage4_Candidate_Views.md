## 核心争议1：AIGC是否构成作品

### 候选观点 1.1：有限肯定说——多回合迭代标准

#### 基本立场

**一句话**：当用户通过复杂提示词和多回合迭代对生成内容施加实质性控制时，可认定为作品；用户为作者。

#### 承接与修正

**承接的前人观点**：
- 蒋舸（2025）：最低限度创造性标准、认知经济性理论
- 崔国斌（2023）：两阶段分析框架、多回合线性改进
- 吴汉东（2020）：三阶段框架、人机共同创作

**支持部分**：
- ✓ 采纳蒋舸的"宽进宽出"政策框架
- ✓ 认同崔国斌的"多回合 vs 单回合"区分
- ✓ 接受降低独创性门槛的认知经济性理由

**反对部分**：
- ✗ 不采纳吴汉东"AI可成为共同作者"（法理基础薄弱）
- ✗ 不同意李伟民的"一律肯定"（过度保护风险）

**修正部分**：
- 在蒋舸"最低限度创造性"基础上，增加"实质性控制"要件
- 在崔国斌框架基础上，细化判断标准

---

#### 现实变化支撑

**技术进步**：
1. 提示词工程复杂化（2023-2024）
2. ControlNet、LoRA等控制工具（2024）
3. 多回合迭代成为主流使用方式（2023-）
4. 局部修改工具成熟（2024-）

**政策转向**：
- 美国版权局2025对"线性修改场景"立场松动

**司法实践**：
- 北京互联网法院接受用户贡献说
- Dreamwriter案虽理论薄弱但确认可版权性

**前提改变**：
- "用户投入少"前提已不成立
- "单回合暗箱"不再是唯一场景

---

#### 可操作规则

**认定标准（三要件）**：

**要件1：复杂提示词**
- 描述性要素≥3项（主体、风格、构图、色调等）
- 或：结构化提示词（含负面提示词、权重设置）
- 或：使用专业术语、参考对象

**要件2：多回合迭代**
- 至少3轮生成-筛选-调整
- 每轮有明确目标导向的修改
- 最终结果与初始生成存在可识别差异

**要件3：实质性控制**
- 使用控制工具（ControlNet、inpainting等）
- 或：精细参数调整（采样器、步数、CFG等）
- 或：LoRA训练/选择

**判断公式**：
```
作品性 = 复杂提示词 + 多回合迭代 + 实质性控制
（三要件同时满足 → 可认定为作品）
```

---

#### 适用条件

**前提条件**：
1. 生成内容在表现形式上符合作品外部特征
2. 用户能证明投入过程（提示词记录、迭代历史）
3. 非抄袭既有作品

**典型适用场景**：
- 设计师使用Midjourney创作商业插画（多轮迭代）
- 艺术家使用Stable Diffusion + ControlNet创作作品
- 广告公司使用AIGC工具设计海报（精细控制）

---

#### 例外情况

**不适用场景**（即使满足三要件）：
1. **训练数据侵权**：如使用侵权数据集训练的模型
2. **高度模仿特定作者**：刻意模仿在世作者风格（侵犯人格权风险）
3. **批量生成**：明显以批量生产为目的（如生成1000张类似图片卖素材）

**争议场景**（可能不认定）：
1. **单回合高质量生成**：即使提示词复杂，但无迭代
2. **简单迭代**：仅微调参数，无实质性变化
3. **AI主导的连续生成**：如AI视频的逐帧生成（人类控制弱）

---

#### 最强反对意见与回应

**反对意见1：违背人类中心主义**

**反对者论证**（王迁2023）：
- 著作权法保护人类创作
- 提示词、筛选不是创作，是使用工具
- 降低门槛将导致权利泛滥

**回应**：
1. 人类中心主义未在立法中明确规定
2. 法人作者已突破自然人中心，AI场景可类比
3. 三要件标准已排除简单场景，无泛滥风险
4. 技术进步改变了"工具使用"内涵：
   - 传统工具（笔）：完全被动
   - AI工具：具有非消极性，但仍受用户控制
   - 用户通过多回合迭代实施创作行为

---

**反对意见2：标准模糊，难以举证**

**反对者论证**：
- "复杂提示词"如何量化？
- "实质性控制"如何判断？
- 用户伪造记录怎么办？

**回应**：
1. 三要件均可客观验证：
   - 提示词：字数、要素数量、技术术语
   - 迭代：seed记录、生成历史、版本对比
   - 控制：参数日志、控制图、LoRA文件
2. 举证责任：用户主张作品性，应提供投入证明
3. 伪造风险：技术手段可验证（模型输出哈希、API调用记录）
4. 类比：摄影作品也面临类似问题，但司法可处理

---

**反对意见3：AI优势悖论**

**反对者论证**（潜在批评）：
- 工具越好，用户投入越少
- 少输入高输出，如何证明用户贡献？
- 本质是AI创作，用户只是触发

**回应**（采纳蒋舸2025论证）：
1. 工具优势恰恰是用户选择的结果
2. 选择优质工具本身体现判断
3. 类比：摄影师选择高端相机，不影响其作品性
4. 关键不在于"投入多少"，而在于"控制什么"
5. 多回合迭代证明用户有明确创作意图

---

**反对意见4：侵犯训练数据作者权益**

**反对者论证**：
- AI使用大量作品训练
- 生成内容可能包含原作品要素
- 保护AIGC = 纵容侵权

**回应**：
1. 训练数据使用是独立问题（专题2讨论）
2. 本观点不主张无条件保护，排除侵权场景
3. 类比：UGC时代也有侵权风险，不因此否定所有UGC作品性
4. 应通过合理使用规则、付费许可等解决训练端问题

---

#### 可证伪点

**可证伪假设**：
1. **假设1**：多回合迭代能产生独创性累积效应
   - **证伪方式**：若实证研究证明多回合迭代不增加独创性
   - **证伪后果**：需修正"迭代"要件

2. **假设2**：三要件标准可有效区分作品/非作品
   - **证伪方式**：若司法实践中大量边界案例难以判断
   - **证伪后果**：需细化标准或增加要件

3. **假设3**：用户能有效举证投入过程
   - **证伪方式**：若技术上无法验证提示词、迭代记录
   - **证伪后果**：需调整举证规则或引入第三方认证

4. **假设4**：宽进政策不会导致权利泛滥
   - **证伪方式**：若保护后出现大量低质量作品主张权利
   - **证伪后果**：需收紧标准或引入"宽出"机制

---

#### 制度成本与收益

**制度成本**：
1. **司法成本**：需审查提示词、迭代过程（中等）
2. **举证成本**：用户需保存记录（低-中等）
3. **识别成本**：第三方难以判断是否AIGC（高）
4. **争议成本**：边界案例增加（中等）

**制度收益**：
1. **激励创新**：鼓励用户精细使用AIGC工具
2. **产业发展**：为AIGC产业提供法律确定性
3. **降低总成本**：避免"假阴性"（蒋舸论证）
4. **技术迭代**：推动工具向可控方向发展

**成本-收益评估**：
- 认知经济性理论（蒋舸2025）支持：降低区分成本优于精确识别
- 假阴性（错误排除真作品）成本 > 假阳性（错误保护非作品）成本
- 宽进宽出：降低入口成本，后端通过合理使用、侵权判定调节

---

#### 与现行法的关系

**著作权法依据**：
- 《著作权法》第2条：作品是"能以一定形式表现的智力成果"
- 第3条：作品类型（美术作品、文字作品等）
- 第11条：署名推定

**需要调整之处**：
- **立法建议**：明确"使用辅助工具创作的作品"可受保护
- **司法解释建议**：细化AIGC场景的独创性判断标准
- **举证规则建议**：要求用户提供投入证明

**过渡期处理**：
- 在立法修订前，可通过司法解释或指导案例明确
- 类比《民法典》第1197条"人工智能致害"的技术中立立场
- 借鉴《反不正当竞争法》对新技术的开放态度

## 核心争议2：独创性门槛

### 候选观点 2.1：动态门槛说

#### 基本立场

**一句话**：独创性门槛应根据AI能力动态调整——AI能力越强,要求用户投入越多；但即使在当前技术水平下，复杂提示词+多回合迭代仍可满足最低限度创造性。

#### 核心论证

**承接蒋舸"最低限度创造性"**：
- ✓ 不追求高独创性
- ✓ 薄版权-厚版权连续谱

**修正与补充**：
- 增加"动态调整"机制
- 技术进步 → 门槛相应提高（轻微）
- 但始终维持"最低限度"基线

**理由**：
1. 技术中立原则：法律标准应随技术演进
2. 避免"AI优势悖论"僵化
3. 保持激励效果：鼓励用户精细使用工具

**可操作标准**：
- 2024年技术水平：复杂提示词（≥3要素）+ 3轮迭代
- 2030年预期：可能需要≥5要素或≥5轮迭代
- 基线：始终低于传统人类创作门槛

## 核心争议3：替代保护路径

### 候选观点 3.1：不需要替代路径

#### 基本立场

**一句话**：在作品路径可行的情况下，不应创设邻接权或其他替代路径；简单场景归入公有领域即可。

#### 核心论证

**承接蒋舸2026邻接权反思**：
- ✓ 完全同意邻接权兜底不可行
- ✓ 采纳古籍点校方法论样本

**理由**：
1. **立法成本高**：创设新权利需修法，成本远高于扩张解释作品
2. **理论基础弱**：邻接权保护传播者，AIGC无传播环节
3. **激励逻辑不同**：投资不是权利基础
4. **公有领域价值**：简单场景归入公有领域，促进传播和再创作

**排除场景的处理**：
- 简单提示词单回合生成 → 公有领域
- 不通过邻接权、不通过竞争法
- 允许任何人自由使用

**竞争法的有限作用**：
- 只在"不正当攫取"场景适用
- 如：大规模爬取他人AIGC内容直接商业使用
- 但不赋予排他权

## 核心争议4：训练数据合理使用

### 候选观点 4.1：有限合理使用说

#### 基本立场

**一句话**：用于训练通用模型的数据挖掘构成合理使用，但模仿特定作者风格的"私人表达型"训练需获得授权。

#### 核心论证

**承接吴汉东2020、蒋舸"宽出"**：
- ✓ TDM规则原则支持
- ✓ 转换性使用理论

**修正**：
- 区分"通用模型" vs "私人表达型"
- 后者不适用合理使用

**四要素分析**（美国标准）：
1. **目的和性质**：转换性使用 ✓
2. **作品性质**：已发表作品 ✓
3. **使用数量**：全部使用，但比例微小 ✓
4. **市场影响**：关键争议点

**市场影响细分**：
- 通用模型：不构成市场替代
- 风格模仿模型：可能构成市场替代 ✗

**具体规则**：
- 通用训练：合理使用
- LoRA训练特定作者：需授权
- 批量使用某作者作品训练：需授权
- 选择退出机制：应尊重

## 总体政策取向

**核心价值排序**：
1. 降低认知成本（认知经济性）
2. 激励创新使用
3. 避免权利泛滥
4. 保护公有领域

**不同于王迁立场**：
- 王迁：人类中心主义 > 产业发展
- 本观点：认知经济性 > 人类中心主义

**不同于李伟民立场**：
- 李伟民：产业发展 > 精确识别
- 本观点：认知经济性 = 精确识别（通过三要件平衡）

**接近蒋舸立场**：
- 都采纳认知经济性、宽进宽出
- 但本观点增加"实质性控制"要件，略严格于蒋舸
