# 大模型训练数据的复制权、合理使用与许可

> [!important] 分析边界
> 本专题依次审查：是否落入复制权、能否适用合理使用、何种情形需要付酬、许可机制如何落地。前一层否定时，后一层可能无须启动；不能把四层合并为“训练是否合法”。

> [!tip] 重心变化
> 新增样本表明，前沿已不止是“合理使用或许可”二选一，而是形成“来源合法性—复制权构成—权利限制／许可—服务者义务—证据与机器遗忘”的五段链条。总图见 [[研究趋势/比较专题/人工智能著作权学术图景：争议、共识与范式迁移|人工智能著作权学术图景]]。
>
> 本争议的新旧文献谱系、六个实体板块、六层训练审查及独立面试模块，见 [[研究趋势/争议专题/深化版/大模型训练数据的复制权、合理使用与许可_深化版|训练数据争议深化版]]。

## 四、学术谱系与趋势

1. **2019—2022：合理使用／TDM 豁免。** 讨论假定输入端会发生大量复制，重点是增设计算机信息分析例外、科研 TDM 豁免或扩张合理使用。
2. **2023—2024：阶段切割与权利构成前移。** 数据准备、投喂、学习、模型形成、输出被分开；非作品性使用、重塑复制权和公众接触标准开始挑战“有副本即侵权”。
3. **2024—2025：条件矩阵取代统一标签。** 营利性、来源合法性、禁用声明、数据市场类型、过拟合、输出替代和主体市场力量共同改变结论。
4. **2025—2026：授权基础设施与程序治理。** 法定许可、集体管理、机器可读退出、来源记录、过错推定、动态注意义务和机器遗忘形成连续制度链。
5. **范式迁移：** 从“训练目的是否转换”的静态抗辩，前移到“前端复制和来源是否合法”，后移到“退出、补偿、证明与删除能否执行”。

| 不能把训练整体作为一个行为评价。 | 各文对分段方式有差异，但普遍区分获取、准备、学习和输出。 |
| “模型学习思想”不能自动洗白前端非法获取或稳定存储。 | 是否因而构成复制、能否合理使用仍有争议。 |
| 合法来源、商业性、过拟合和市场替代是重要变量。 | 各变量权重和证明责任尚未统一。 |
| 单一的全面许可或全面豁免都面临实施困难。 | 默认规则究竟是先许可、法定许可还是选择退出仍属核心争议。 |
| 训练透明度和来源记录是权利人行使权利的前提。 | 应避免不成比例披露商业秘密或形成一般监控。 |
| 输出端复现与替代风险应独立评价。 | 对输入端宽免不等于输出端免责，反之亦然。 |

## 五、最难调和的逻辑漏洞与压力测试

> [!warning] 最难调和之处
> 学界尚缺可靠方法证明“某一训练使用”与“某一作品现实或潜在市场受损”之间的因果链。若只看输入复制，容易忽略非表达性学习；若只看输出替代，又可能让权利保护取决于事后、难以追踪的模型行为。

| 新变量 | 哪一方首先承压 | 原因 |
|---|---|---|
| 强制机器可读退出＋低成本集体许可 | 以交易成本支持原则合理使用的一方 | 许可不可行的事实前提减弱，但仍须评估平台垄断和孤儿作品。 |
| 可验证删除（模型可证明忘却特定作品） | 认为退出无法执行的一方 | 退出可以从形式权利转为可执行救济。 |
| 输出能够高概率复现训练作品 | 非表达性／纯统计学习的宽免路径 | 输出证据强化了训练吸收具体表达及市场替代的推论。 |
| 完全合成、获授权或进入公有领域的数据足以达到同等性能 | 主张未经许可训练具有不可替代社会收益的一方 | 必要性和比例性依据显著下降。 |
| 独立审计可验证数据来源和模型遗忘效果 | 反对举证转移或认为退出不可执行的一方 | 黑箱和技术不可行性理由被削弱，但审计成本与商业秘密仍须权衡。 |
| 训练仅流式读取且不保留可还原副本 | 以稳定复制为当然起点的一方 | 必须说明瞬时技术过程如何满足复制构成以及何种法益受损。 |
| 训练集长期保存、可逐项检索并直接提供原作 | 非作品性使用／复制权否定的一方 | 数据库本身已产生独立的表达接触和传播风险，难以被训练目的覆盖。 |
